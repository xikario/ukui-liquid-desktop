# 任务视图开关与托盘向上展开修复（2026-10-07）

## 架构与核验

任务栏仍运行系统的 `/usr/bin/ukui-panel`，液态效果由 `ukuiliquidpanel` Qt 样式插件提供。本次在插件内适配原生 Qt 控件，没有替换任务栏，也没有修改固定应用、托盘分类或用户布局配置。

目标机安装版本为 `ukui-panel 3.26.0.0-0k3.21oemccd3000m0.26.u`。隔离运行这一实际二进制时，观察到 `org.ukui.panel.settings/showtaskview=false` 与可见的 `TaskViewButton` 同时存在；不能仅依靠较旧的公开源码推断当前 OEM 初始化行为。

当前 OEM 托盘的 `StatusNotifier_statusNotifierWidget` 布局把隐藏组放在 `StatusNotifierStorageArrow` 前，可见组放在箭头后，固定组位于独立控件。原来的箭头会在任务栏布局中展开隐藏组，因此挤动应用图标。

## 修改

- **任务视图**：读取系统 `showtaskview` 开关，初次显示、原生布局调整和外部设置变化后保持一致。关闭时同时隐藏相邻分隔线。通过 GIO 的公共 C API 监听单个设置键；连接后读取该键，以满足 [GSettings changed 信号的要求](https://docs.gtk.org/gio/signal.Settings.changed.html)。缺少 GIO 或对应 schema 时保留原生行为。
- **隐藏图标**：将原生隐藏组按钮放入箭头上方的独立液态弹层，保留按钮实例、应用连接及原生鼠标坐标处理。可见组与固定组留在任务栏，展开与收起不改变其位置。最多五列，较多图标在弹层内滚动。
- **交互与更新**：支持原生点击、右键、Esc 和点击外部收起；任务栏隐藏或移动时收起。应用退出后使用 `QPointer` 清理按钮；原生重建布局或拖动排序后重新归位，保留最新顺序。打开时取消原生箭头提示，避免提示框遮挡弹层。
- **资源**：设置变化及相关控件结构事件触发一次合并处理，不新增周期轮询；稳定后不反复创建弹层或重建图标网格。共享弹层现在遵循明确指定的 `Above` 位置，即使下方有空间也优先向上展开。

适配基于 Qt 公开对象与布局接口，没有使用 OEM 私有字段偏移。不同 OEM 若没有匹配的托盘容器或箭头，将保留原生托盘行为，需要另外核验；本次正向证据针对上面的目标机版本。

## 补充修复（2026-10-07 14:06）

- **三级托盘菜单消失**：dbusmenu 子菜单在显示后才填充，空菜单以零宽映射，得到只有几像素的遮罩，后续 Resize 又因材质为空跳过重建。现在可见菜单的每次 Resize 都重建材质与遮罩，空菜单首次变大时补采一次背景。
- **弹层偶尔变一行或内容消失**：OEM 在 `resetLayout`、`exchangeHideAndShow` 与 `resetIcon` 中对隐藏组按钮调用 `setVisible(false)`，旧逻辑仅在布局变化时重新显示。现在每次同步都恢复按钮可见；SNI 状态为 Passive 的按钮保持隐藏且不占格子。列数统一为最多五列（之前代码实际为三列，与上文描述不符）。
- **减少一行后弹层悬空**：新增 `Shell::reanchor`，打开状态下尺寸或箭头位置变化时，向上弹层保持底边贴住箭头，仅补采新露出的屏幕区域。托盘容器移动不再直接关闭弹层，改为跟随。
- **弹层背后的“折叠显示图标”残影**：OEM `CustomToolTip` 淡出期间被截入玻璃材质。现在指针进入箭头时（OEM 显示提示之前）预采背景，打开时复用；展开状态下 OEM 再次显示的提示会立即隐藏。
- **箭头拖动**：OEM `mouseMoveEvent` 无条件启动 `QDrag`，现在箭头上的所有移动事件都被拦截。
- **展开/收起特效**：沿用单个 `QVariantAnimation`，无常驻定时器。气泡从箭头沿展开方向生长并带轻微回弹，内容延后淡入并上移 6 px 落位；收起时反向。“减弱菜单动画”开启时直接显示或关闭。

验证：49 项测试共 48 项通过、1 项 GPU 测试跳过，新增 OEM 隐藏调用、五列两行、增减行底边不变、重锚不重复采样、预采样复用等用例。隔离 Xvfb 中实际 OEM 任务栏注册 7 个隐藏托盘项，打开状态下 7→6→5→4→7 增减，弹层底边始终为箭头上方同一位置；Passive 切换与 8 次快速开关无异常。已安装，备份位于 `apps/ukui-panel-liquid/releases/20261007-140627-8zqz0kma/`，桌面弹层无提示残影。


## 退出抖动与剩余交互修复（2026-10-08）

用户提供的录屏显示：应用从托盘右键菜单退出后，隐藏图标反复在弹层和原生任务栏之间移动，任务区被压缩或恢复，箭头和弹层左右跳动；点击收起后才停止。

### 根因及对照

前面的隔离测试将 `org.ukui.panel.settings/statusnotifierbutton` 固定为 false，因此没有触发这条分支。实际桌面残留的是 true，这是 OEM 的**横向展开状态**，并非图标分类偏好。原生展开逻辑在图标更新、状态变化及应用退出时重新布局，与独立向上弹层争夺按钮。

在私有 Xvfb/D-Bus/bwrap 环境，以实际 OEM 任务栏、1.5 倍缩放、普通主窗口加托盘模拟应用复现：初始展开状态 true，菜单 Exit 同时关闭主窗口、注销 SNI，随后剩余项周期更新图标及 Passive/Active 状态。旧插件的托盘宽度在 33/198/231 px 间变化，任务区在 865/898/1063 px 间变化；226 个采样中有 10 次全部 6 个图标回到原生主栏、弹层为零个。收起后立即稳定，与录屏一致。纯注销和展开状态 false 的控制组没有这类持续跳动。

修复后由独立弹层接管展开状态，创建适配器后将原生横向展开归 false，并监听其变化；只有状态为 true 时才写一次，不连续写设置。隐藏/常显/固定图标的分类配置保留。相同复现负载下，托盘保持 33 px、任务区保持 1063 px，箭头与弹层横向位置稳定；Passive 状态只改变弹层中的格子。OEM 同步重排中可能短暂将不可见按钮重新挂到原容器，下一轮合并处理立即收回，不再形成可见的主栏与弹层来回切换。

### 其他修复

- 隐藏组优先读取 OEM `getActionArea()`，避免按箭头前后的位置误分类。首次准备中的未定义组才用位置兜底。网格最多三列，4/5/6 个图标也保持多行；增减行保持底边贴箭头。
- 弹层重排不再额外刷新原托盘几何；箭头图标复用缓存，只有图标实际变化才 `setIcon`，避免布局事件反馈。
- 根右键菜单位于被点击按钮上方，异步变大仍保持锚点，子菜单沿用原生级联位置。新点击取消尚未匹配的菜单请求，同一次右键的祖先传播保持关联。
- 50 ms 提示消退等待使用可撤销定时器：点击外部、鼠标离开、隐藏面板、再次点击和 Esc 均可取消；键盘打开不因鼠标位置取消。
- 弹层通过真实 `QDrag` 在 Drop 时排序，稳定 Id 保存于 `liquid-panel.ini` 的 `tray/hiddenOrder`；跨隐藏/常显组复用 OEM 设置接口，不将失效的布局索引传入原生动画。拖动结束后不误启动应用，也不吞掉第一次右键。
- 开合动画在配置起止值之前固定进度与时长，并清除旧时间，修复第二轮起退化为 1 ms 的问题。保留回弹、淡入和快速反向。

Qt 将 OEM 插件以局部符号可见性加载，原先 `dlsym(RTLD_DEFAULT)` 无法取得状态及 Id。现在通过实际类的元对象定位已加载模块，再解析其导出接口，不加载第二份插件。Id 首次缓存，初始化为空最多延迟重读一次；不在每次同步发 D-Bus 查询。此适配仍限定已核验的 OEM 版本，依赖导出的 C++ 方法而非私有字段偏移。

验证包含四档缩放、实际鼠标拖动及持久排序、常显图标拖到箭头后原生分类配置更新、根菜单位置、三级菜单真实动作触发、展开状态 true 的复现对照。Clash 的真实三级菜单由用户确认已解决，本轮保持共享遮罩修复。复现证据和脚本位于本地 `apps/ukui-panel-liquid/build/artifacts/panel-exit-repro-20261008/`；其他原生验证位于 `panel-reorder-review-20261007/`。周期更新属于合成压力场景，记录器也消耗资源，不能把采样 CPU 外推为日常性能改善百分比。
