# 音乐小组件：可配置的多客户端接入

日期：2026-10-01。延续本次大更新，仅本地构建与安装，不提交或推送 Git。

## 使用

打开设置中心的“音乐播放器”。先手动打开一次播放器，再点“添加已运行的客户端”；从服务所属进程自动识别可执行文件、工作目录与桌面启动入口。已配置但启动信息为空的运行客户端也会生成识别草稿。“从运行进程识别”可更新所选客户端；不再弹出程序文件选择器。也可“手动添加”填写显示名称与 `org.mpris.MediaPlayer2.*` 服务名。勾选启用后点击“应用”，音乐小组件立即重新选择连接。

启动程序与参数分别填写，参数每行一项，含空格的路径不加引号。启动程序可留空；只要客户端已运行并提供接口，就能接入。自动识别优先使用匹配且无歧义的桌面入口，经目标机现有的 `gtk-launch` 保留软件自己的启动包装；否则使用进程可执行文件与工作目录。保留 AppImage 原始路径，不保存其临时挂载路径。手动编辑程序、参数或服务名会取消旧的自动启动入口，防止覆盖用户的手动选择。启动按钮只在用户点击时运行配置程序，直接传递参数，不使用 shell，并清除继承的 `ELECTRON_RUN_AS_NODE`。

现有用户默认保留 Strawberry 及其便携版选择。检测到其他客户端不会自动启用，便于排除浏览器或视频播放器的 MPRIS 服务。空启用列表也是有效配置。

## 选择规则

- 只在已启用配置中选择，同时保留一个播放连接。
- 优先比较 MPRIS 服务所有者进程的 `/proc/<pid>/stat` 启动时间，选择最近启动的客户端；小组件启动晚于播放器时也适用。
- 进程时间相同则按本次服务注册顺序排序。读取启动时间失败时，候选集合整体回退到本次观察顺序；对于冷启动且无已知历史的同序项，稳定按服务名区分。
- 名称匹配自身及以 `.` 分隔的多个实例，不会把 `strawberryevil` 当作 `strawberry`。
- 当前客户端退出后选择仍在运行的最新候选；全部退出清空显示。较旧客户端的播放/暂停变化不改变选择。
- 自动切换仅改变小组件控制对象，不暂停、结束或重新启动客户端。播放能力由各客户端提供，缺少能力时对应控件禁用。

## 实现与边界

将专用 `StrawberryPlayer` 重构为 `MprisPlayer`，保留原有播放、定位、音量、封面和可见性行为。服务发现、所属进程查询及播放通信均异步，进程启动信息在工作线程读取。

信号绑定到选中客户端的唯一 D-Bus 所有者，接收时再次校验发送者；切换增加请求版本，拒绝旧属性/位置/封面回复。进度与音量拖动保存连接身份；进度另外保存曲目身份，防止客户端间相同 track ID 造成误控制。

新增独立音乐客户端设置表单，配置存储在 `desklets/music/clients` 的版本化 JSON 中，另记录上次接入客户端用于启动按钮选择。列表、检测与表单支持草稿，只有应用后保存。仅刷新客户端目录或选择检测结果不制造草稿；为已有空启动配置补全信息会产生草稿，应用后保存。非法或重复服务名不覆盖原配置。

X11 上点击打开时，按当前服务所有者 PID 与进程启动时间校验身份，再从窗口管理器客户端列表定位所属窗口，恢复最小化并发送前置请求。无法定位窗口时才使用 MPRIS `Raise`。不会按标题猜窗口、自动重开仍在运行的播放器或改变播放状态。规范来源：[EWMH 窗口激活](https://specifications.freedesktop.org/wm/1.5/ar01s03.html)。

只支持客户端主动提供的 MPRIS 接口。某些软件或版本需要自行启用相应插件；单靠启动命令无法给未提供该接口的软件补出控制能力。不接管播放列表或音频引擎，不依赖常驻 playerctl 轮询。

规范来源：[MPRIS 2.2](https://specifications.freedesktop.org/mpris/latest/)、[根接口与前置能力](https://specifications.freedesktop.org/mpris/latest/Media_Player.html)、[D-Bus 服务所有者](https://dbus.freedesktop.org/doc/dbus-specification.html)。
