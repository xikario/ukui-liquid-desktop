# 视频壁纸下小组件背景残影修复 · 2026-10-06

## 可观察的问题

用户截图及本机画面中，智能空间收起的蓝色星形入口外出现一整块静止矩形；音乐等小组件的透明圆角也露出静止背景，和正在播放的壁纸接不上。

原因是原生视频位于 Qt 画布之上，需要避让组件。但之前仅使用 QWidget 的窗口 mask；mask 为空就扣除整个矩形。智能空间和液态小组件为保留抗锯齿透明边缘，本来就没有二值窗口 mask，结果透明像素也被错误扣除，露出画布缓存的首帧。

玻璃内部使用首帧是既有节省资源策略，材质保持静止属于该策略。本次修复透明区域露出方块的问题，没有改成逐帧抓取视频做玻璃模糊。

## 实现

- `VideoWallpaperRegion.h` 区分实际绘制区域和鼠标点击区域。小组件发布缓存的绘制区域，视频裁剪与原有窗口 mask 求交；没有发布区域的其他组件保留既有行为。
- 音乐、时钟、日历和活动统计共用 `LiquidDesklet`，在材质完成时按非零 alpha 提取轮廓，保留抗锯齿像素；分数 DPR 向外覆盖，避免视频覆盖边缘。调整尺寸期间先用保守圆角轮廓，随后采用新材质的实际 alpha。
- 智能空间展开时按玻璃或普通主题轮廓避让；收起时只保留星形图标的 alpha 轮廓，周围继续显示视频。完整的 52×52 点击区域不变，也没有给 QWidget 增加硬边窗口 mask。
- 专用动态属性变化、显示隐藏、移动缩放触发既有 16 ms 单次合并更新；普通绘制复用区域。没有增加持续轮询、视频解码或逐帧材质工作。

## 验证

Release 程序及测试构建通过，14 项 CTest 全部通过：

- `desktop_video_trial`：读取实际发送给替身播放器的裁剪消息，检查音乐圆角、玻璃主体、缩放，以及智能空间展开／收起／重新展开；同时检查点击 mask 不变、普通音乐绘制不重建材质。
- `smart_space_wallpaper_sync`：通过隔离的系统及 Fences 壁纸事件，验证智能空间和音乐更新到新背景，以及自定义壁纸仍优先。
- 以下四类测试分别覆盖 1／1.5／2 倍缩放：`desktop_desklets`、`desktop_music`、`desktop_smart-interaction`、`desktop_smart-space-position`。

本机安装后，用当前 `【哲风壁纸】亭台-侠客-古月方源.mp4` 验证。截图确认星形入口外的矩形残影消失。读取真实原生播放器窗口的 X Shape 区域，确认星形周围及音乐透明圆角属于视频区域，星形图案及音乐玻璃主体受到保护。当前桌面 DPR 为 1.5。

连续 8 秒只读观测中，视频仍使用 VAAPI 播放，位置／循环次数变化；四个小组件的材质重建次数及钟面材质重建次数没有增加，几何不变。这是缓存稳定性检查，不是完整 CPU 性能对照测量。

安装检查全部通过：运行二进制与构建一致，小组件几何、智能空间状态、系统监视显示状态、设置及桌面布局均保留，原视频选择自动恢复。使用正常退出与启动过程重新加载，没有调整用户壁纸选择。
