# 开始菜单右键裁切与残影修复

日期：2026-09-30。

## 原因与修复

开始菜单先显示“正在检查安装来源…”，后台查询完成后更新卸载项文字。Qt 随文本改变菜单尺寸，共享液态菜单此前仅在 Show 时生成一次材质和原生 QRegion，因而继续使用旧轮廓。旧版实机 WPS 右键菜单已复现右侧呈直线裁切；隔离测试也复现从短标签变成长标签时右侧超出旧遮罩。

共享 MenuSkin 现在在 Resize 时同步重建材质与圆角遮罩，刷新完整窗口。复用打开前的背景，不在菜单已显示时抓取它自身；重叠背景像素保持位置，新增区域只延展原采样的边缘。更新后重新约束屏幕范围，避免标签变长后溢出屏幕。隐藏时恢复原样式和遮罩，释放采样与材质。

本地部署还发现旧版正常退出卡在 KeyInterceptor::ungrabWinKey 的 XCloseDisplay。GDB 栈确认主线程在监听连接的同步回复上等待；停止和释放 XRecord 的请求仍缓存在另一个控制连接中。已在关闭监听连接前通过 XSync 送达控制请求，新增正常退出测试。
