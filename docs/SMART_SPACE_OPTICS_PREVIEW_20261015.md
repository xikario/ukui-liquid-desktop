# 智能空间水滴玻璃预览（2026-10-15）

参考用户附件的斯涅尔折射、微色散、方向性高光和内侧反光，新增一版可切换的智能空间材质。原有布局、搜索行为、细边线和中心阅读底色继续使用现有实现。

## 入口与回退

- 智能空间“更多”菜单 → “水滴折射玻璃（预览）”：开启时进入液态玻璃皮肤；取消后恢复原柔光材质。
- 智能空间自身设置 → 外观 → 液态玻璃质感：选择“轻量柔光（原样式）”或“水滴折射（预览）”。
- 保存为 `smartSpace/glassOptics`，默认 false。本机试用可单独开启，其他用户升级后继续保留原样式。
- D-Bus 增加 `setSmartSpaceGlassOptics(bool)` 和 `smartSpaceGlassOptics()`，用于设置与只读核验；不主动展开隐藏的组件或抢占应用前台。

## 处理了附件中的问题

1. **稀疏边缘查找表**：每项 12 字节，只存 22 逻辑像素宽的边缘带，不创建全尺寸 LUT 或未使用的遮罩。尺寸与 DPR 为几何缓存键，物理参数为固定常量；换壁纸复用几何，切回原样式释放表。
2. **局部背景坐标**：清晰源使用当前组件采样区的一半分辨率，按实际物理尺寸映射。没有将全局位置简单除以二；采样带边界检查，支持奇数尺寸与小数缩放。
3. **平滑、克制的彩边**：折射偏移保留 1/16 像素，色散保留 1/8 像素，使用双线性采样；最外侧细边保留原材质，避免高对比壁纸出现生硬的彩色颗粒边。
4. **精确视频轮廓**：光学步骤保持每个像素的 alpha，最终材质经过原有 scrim/grain 后生成精确 coverage。coverage 随材质缓存，DPR 不匹配时先使用新缩放的临时轮廓，绘制后更新精确值。未退回固定近似圆角。
5. **保持静态缓存链**：普通重绘、输入与悬停不重新计算折射。继续使用现有一次性指针节流；未增加视频取帧、共享内存服务、全局轮询或 GPU 调频策略。

## 验证与资源成本

首轮 11 项通过：四档光学测试、壁纸同步、三档智能空间交互及三档启动/隐藏位置回归。平滑采样调整后，四档光学测试再次通过；最终 coverage 的 DPR 条件补充后，四档光学与壁纸同步 5 项重新通过。

光学测试逐像素检查 alpha 与合法的预乘通道，检查中心像素保持不变、边缘确实变化、局部重绘复用缓存、换壁纸复用几何、设置保存与恢复、切回原样式逐像素一致及表内存释放。生成的前后对比来自真实 SmartSpaceWidget，使用合成测试壁纸及隔离目录，不含用户文档。
