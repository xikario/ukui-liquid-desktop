# 智能空间水滴玻璃预览（2026-10-15）

参考用户附件的折射、微色散、方向性高光和内侧反光，新增可切换的智能空间材质。首轮保留中心底色；第二版改为深磨砂和双圆角折边，第三版继续完善通透底色、色彩与阅读对比度，见文末。搜索与索引行为保持原有实现。

## 入口与回退

- 智能空间“更多”菜单 → “水滴折射玻璃（预览）”：开启时进入液态玻璃皮肤；取消后恢复原柔光材质。
- 智能空间自身设置 → 外观 → 液态玻璃质感：选择“轻量柔光（原样式）”或“水滴折射（预览）”。
- 保存为 `smartSpace/glassOptics`，默认 false。本机试用可单独开启，其他用户升级后继续保留原样式。
- D-Bus 增加 `setSmartSpaceGlassOptics(bool)` 和 `smartSpaceGlassOptics()`，用于设置与只读核验；不主动展开隐藏的组件或抢占应用前台。

## 首轮：处理了附件中的问题

1. **稀疏边缘查找表**：每项 12 字节，只存 22 逻辑像素宽的边缘带，不创建全尺寸 LUT 或未使用的遮罩。尺寸与 DPR 为几何缓存键，物理参数为固定常量；换壁纸复用几何，切回原样式释放表。
2. **局部背景坐标**：清晰源使用当前组件采样区的一半分辨率，按实际物理尺寸映射。没有将全局位置简单除以二；采样带边界检查，支持奇数尺寸与小数缩放。
3. **平滑、克制的彩边**：折射偏移保留 1/16 像素，色散保留 1/8 像素，使用双线性采样；最外侧细边保留原材质，避免高对比壁纸出现生硬的彩色颗粒边。
4. **精确视频轮廓**：光学步骤保持每个像素的 alpha，最终材质经过原有 scrim/grain 后生成精确 coverage。coverage 随材质缓存，DPR 不匹配时先使用新缩放的临时轮廓，绘制后更新精确值。未退回固定近似圆角。
5. **保持静态缓存链**：普通重绘、输入与悬停不重新计算折射。继续使用现有一次性指针节流；未增加视频取帧、共享内存服务、全局轮询或 GPU 调频策略。

## 第二版：深磨砂与厚折边

用户认为首轮区别不明显，并提供第二份设计。本版替换同一个可选预览，原样式与切换入口保留。

- **中心深磨砂**：半分辨率边缘源做轻度柔化；四分之一分辨率的中心源做三遍可分离均值滤波，近似高斯模糊。半径随 DPR 缩放，放大后背景线条融为柔和色块。仍采用原有深色阅读遮罩，未照搬附件较浅的遮罩参数。
- **双圆角折边**：外圆角 19、内平台圆角 12、折边 21 逻辑像素。内外圆角共同确定法线，避免折边宽于外圆角时内平台退化成尖角。直边采样最大拉扯约 48 逻辑像素，圆角加厚；这是艺术化透镜模型，不声称为物理光线追踪。
- **三段光影**：内侧暗槽、弧面亮带、约 2.2 逻辑像素外沿高光。光照项改用有符号数，色散维持亚像素采样。内容边距由 12 增至 16，切回原样式恢复 12。
- **继续复用缓存**：边缘表仍为每项 12 字节的稀疏缓存，不采用附件的全图 LUT；滤波中间图在生成后释放，无新常驻定时器、逐帧视频采样或额外完整材质副本。
- **圆角与回退**：深磨砂最终转回与原底图相同的预乘 ARGB 格式，避免 Qt RGB32 路径造成圆角 alpha 差一级。折射步骤不修改 alpha，视频 coverage 继续来自实际材质像素。切换样式同时清空背景缓存，避免原样式误用上一版深磨砂。

## 第三版：通透底色、色彩与可读性

用户再次要求沿附件思路完善；本次附件与上一份内容相同。本轮补齐第二版尚未采用的色彩层，继续使用现有深磨砂与双圆角几何：

- 使用 72–98 的渐变暗色遮罩、柔和顶光，让背景色透出；边缘在保持灰色中性的前提下适度增强饱和度。原有颗粒仍只加一次，没有照搬附件的第二层伪随机颗粒。
- 用 `SourceAtop` 重着色已有材质，逐像素 alpha 保持不变。沿用现有稀疏表、亚像素采样、DPR 缓存键和精确视频 coverage；没有新增完整 LUT、材质副本缓存或常驻定时器。
- 较浅的艺术化遮罩在白色壁纸上会让白字发淡，因此检查最终 scrim/grain 后的阅读区，再补足必要的压暗量。沿用 `Palette` 的正文 7:1、辅助文字 4.5:1 目标；遮罩通过已有折边混合权重向外衰减，保留外沿亮度。深色背景满足目标时不额外压暗。
- 对比度检查使用 24 逻辑像素间距采样，并留出量化与采样间隙余量；不声称对所有可能壁纸的每个像素作形式化保证。回归使用更密的 9 逻辑像素网格检查最终阅读区。
