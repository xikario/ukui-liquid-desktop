# 小组件缩放磁吸（2026-09-30）

## 行为

六类组件接入同一套缩放边缘计算：时钟、活动、音乐、日历、系统监视、智能空间。

- 组件与分区可见边缘：12 逻辑像素内吸附；桌面边缘：32 逻辑像素内吸附，与四个新组件原有移动手感一致。
- 可对齐同侧边缘，也可贴到对方近侧边缘；右/下使用排他坐标，避免 1 像素重叠或空隙。
- 隐藏组件、收起的智能空间、与当前尺寸无相邻跨度的远处对象不参与吸附。设置窗口等普通子窗口也不参与。
- 原四组件锁定时不能缩放；缩放时固定左上角、遵循各自最小/最大尺寸，并约束桌面范围。
- 系统监视保留等比例和原贴屏侧的固定行为，固定边缘在鼠标按下时确定，拖动过程中不更换锚点。
- 智能空间保留等比例缩放，置顶窗口使用桌面坐标计算，不改动开合动画和原有编辑交互策略。
- 拖离阈值立即解除吸附，不新增弹簧动画或永久定时器。

磁吸是尺寸选择辅助，不是碰撞阻挡：继续拖过另一组件仍可重叠。两条目标边与等比例约束冲突时只吸附其中一条，优先屏幕边缘，其次最近边缘。

## 源码

`src/WidgetResizeSnap.h` 提供几何计算，`DesktopCanvas::snappedWidgetResize` 统一收集可见分区/组件；三类现有缩放入口调用它。计算只在拖动事件发生时运行；壁纸/液态材质缓存沿用原实现。
