# 时钟表盘公共液态材质（2026-09-30）

时钟、音乐、日历原本都使用 `LiquidDesklet` 的公共外层材质，运行诊断确认三者均在 GPU 模式。时钟所在位置为纯蓝天空，缺少音乐/日历所在云层的颜色和纹理；内部表盘还绘制了半透明深色圆盘，因此看起来更平。

本轮保留外层材质、尺寸、位置、字号、指针与按钮样式，时钟表盘改用公共 `LiquidOpticsRenderer::renderControl` 的圆形玻璃镜片。首版曾错误地把已经压暗的外层卡片再次作为镜片输入，造成深蓝平面感；随后改成直接采样表盘位置的原始壁纸，并补充低强度方向性边缘反光与弧面高光。它只采样缓存的底板，不采样文字/指针，不重复套用底板压暗。倒计时圆面使用相同方式，进度环内缩 3 个逻辑像素。没有新增独立着色器或改变音乐、日历材质参数。

镜片按底板图像缓存键与表盘几何缓存，只有背景、位置、尺寸或页面形状改变时重建；秒针维持每秒更新，不重新运行材质着色器。GPU 不可用时沿用公共控件的 CPU 回退。运行诊断 `desktopWidgetsStatus` 增加时钟镜片的 `faceGpu`、`faceMaterialBuilds`。

验证：1×、1.5×、2× 时钟/活动测试及 1.5× 音乐、日历回归共 5/5 通过；新增表盘透明外角、实心内部、DPR、连续 tick 缓存复用、换壁纸刷新检查。实际桌面检查时钟和倒计时两页，确认外层及表盘均为 GPU 模式；10 秒秒针运行期间镜片重建次数不变。

仅更新用户级 Fences 二进制并通过 D-Bus 正常退出后重启，四个小组件均恢复原位置；未修改壁纸、布局、自启动入口或倒计时数值。安装前备份在 `apps/ukui-fences/releases/20260929-235903-clock-lens/`，截图及诊断留于 `/tmp`，不入库。此次未执行整机重启或长期性能测试。纯色天空区域依然会比彩色云层显得素净，这是背景差异。

实际桌面复核：首次改为原始壁纸后，表盘边缘和高光可见；由于时钟所在位置的原壁纸本身是纯蓝天空，其中心仍会呈蓝色，这是背景内容而非备用底板。与橙色云层区域相比颜色变化天然较少。
