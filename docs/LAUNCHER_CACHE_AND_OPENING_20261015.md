# 开始菜单打开与绘制缓存优化（2026-10-15）

本轮依据用户提供的开始菜单优化建议核验真实实现，保留现有 GPU 光学材质、160 ms 图标悬停、侧栏胶囊、鼠标反光和背景准备完成再显示的规则。仅优化开始菜单，不修改分区的默认材质或既有布局。

## 核验结果与取舍

- **成立**：打开前同步刷新使用记录、同步 AccountsService 查询与头像解码；每次重建最近应用按钮；应用动画重复光栅化描边文字；GPU 控件渲染前额外裁片；全量移除再添加文件监听；窗口属性操作重复连接 X11。
- **不成立**：`m_controlOptics.setWallpaper(m_image)` 不会立即模糊或上传整张图。公共 `LiquidOpticsRenderer::renderSurface()` 仅在 `!control` 时准备扩散图，控件直接读取 `m_source`。改成原壁纸的 `result.material` 会改变控件取样来源，使其不再基于已渲染的主面板。
- **不采用**：只监听父目录。父目录的变更通知不能替代 `.desktop` 内容原地修改通知。本轮保留文件监听，用差集更新，原子替换后补回失效监听。
- **不采用**：直接贴旧背景后再更新。用户之前遇到的旧系统壁纸闪现仍由“核对实际背景并准备完成后映射”防止。
- **不采用**：附件的全幅 Dual-SDF LUT 和加厚暗槽。它会改变已认可的材质，逐像素表还会随 DPR 平方增长；单个静态可变缓存也不适合并行准备多个实例。附件中的 0.7 ms、降低 85% 和零延迟没有本机测量依据。
- 高光定时器原本就会收敛停止。尾部有限次动画用于保留平滑，未将正常收敛改成突停。

## 本轮实现

### 打开路径

使用记录在后台刷新，单个窗口最多一个活动任务，多次请求合并。目录重扫或新启动记录会改变修订号；过期结果不能覆盖更新的应用目录。完成时沿用当前搜索文字，仅在最近使用排序真正改变时重排，并保留滚动位置。

XBEL 与最近应用配置缓存解析结果，以路径、设备、inode、大小和纳秒 mtime/ctime 识别文件变化。使用 XDG 数据目录；同大小、同 mtime 的替换也会失效。读失败或部分 XML 不永久缓存；刷新前清空每个应用的使用计数，防止反复累计。正则表达式复用编译结果；缓存有互斥保护，可同时服务目录扫描与使用记录工作线程。

头像使用工作线程中的有界原始 D-Bus 消息，每次调用最多 500 ms，图片使用 QImage 解码。相邻打开在 30 秒内复用结果；没有常驻轮询。仅使用当前账户的头像候选，不再回退到其他用户的头像。圆形头像按 DPR 缓存，重绘不重复缩放与裁剪。

开始按钮停留 60 ms 后执行一次隐藏预热，离开使请求失效，不映射、不激活窗口。点击或 Win 键仍核对当前屏幕像素；同背景的活动准备可接入新的完成回调，背景改变则丢弃旧结果。预热不能保证零延迟，键盘呼出和冷启动仍有截图、扩散、GPU 渲染及映射成本。

### 绘制与监听

最近应用按 desktop 路径复用按钮、动画和信号连接，变化时更新实际数据，移除过时控件。图标缓存为 56×56 逻辑像素的精灵，按压版本按需创建。描边文字缓存为带上下保护边的独立图层；字体、DPR、配色、文字、相对时间或局部亮度光晕改变会重新光栅化。悬停与按压动作保留。

侧栏按脏区跳过无关按钮的绘制，保留静止时的胶囊。GPU 控件成功时不再先做一次无用裁片，CPU 回退外观沿用原算法。切到 CPU/清空材质时释放控件旧背景引用。

应用监听仅增删差异，原地修改与替换继续有效。开始按钮复用现有 X11 事件连接，主菜单复用已有指针连接，生命周期结束时统一释放；不增加定时属性修复。

## 验证

7 项开始菜单 CTest 全部通过：元数据、三档（1 / 1.5 / 2）右键来源与启动查询、三档指针/缓存回归。新增实际使用入口覆盖：阻塞使用记录文件时 GUI 仍能响应；请求合并；旧结果不能覆盖更新的应用目录与搜索输入；最近应用按钮复用；图标同路径替换；字体、配色与亮背景光晕失效；头像短期复用；原地修改 `.desktop` 后目录更新；悬停预热不显示窗口；局部与全窗口重绘无残影。既有取消打开、壁纸变化首帧及弹窗层级用例继续通过。

真实桌面显示连接上的无界面 GPU 材质测试通过 109 个断言，未映射测试窗口或移动真实鼠标。包括三个 DPR 的材质/控件、透明角、按压、缓存、CPU 回退、异步结果相同、同背景活动准备仅一个任务、销毁后不回调与只接受最新背景。观察了合成背景上的实际窗口截图，文字和图标边缘正常。

最终二进制另作一次独立 Xvfb 对照，没有与构建或其他测试同时运行。缩放 150%，CPU 缓存材质，约 120 Hz 脚本鼠标（各 703 左右事件），连续移动采样各 6 秒，按单核进程 CPU 计算：

| --- | ---: | ---: |
| 菜单打开且连续移动 | 21.31% | 17.82% |
| 打开静止（各约 2 秒） | 0.5% | 0.5% |
| 移动结束收敛后（各约 2 秒） | 0% | 0.5% |
| 关闭前/后（各约 2 秒） | 0% | 0% |

移动样本降低约 16%，不是附件宣称的 85%。反向顺序的前一轮观察为 20.99% → 17.32%，方向一致。短时间采样有 CPU tick 量化和调度误差，0% 不表示长期绝对零消耗；不能将 Xvfb 的 CPU 材质数据当作真实显卡帧率、整机功耗或所有背景下的性能。首次 GL 预热仍有开销，部署日志观测 716 ms；没有声称冷启动/Win 键呼出零延迟。

已备份并正常退出旧开始菜单，安装后保持隐藏，开始按钮位置与尺寸相同。构建、安装与实际运行文件 SHA-256 一致，新 PID 6933。皮肤、字体、透明度、固定项与侧栏偏好未变；验证期间用户继续切换应用，最近使用记录正常更新，没有回滚历史。没有重启 Fences 或任务栏。运行日志没有崩溃或 shader 回退标记。
