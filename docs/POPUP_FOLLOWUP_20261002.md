# 弹窗层级、任务栏图标与首帧修复 · 2026-10-02

本轮处理用户截图中的五处问题，并保留最小化、关闭、任务栏恢复和原有玻璃特效。未提交或推送 Git。

| 问题 | 最终处理 |
| --- | --- |
| 分区图标选择被设置中心盖住 | 普通弹窗继承所属顶层窗口的置顶层级，显示时提升并激活；选择器使用 Fences 设置图标与原生应用身份 |
| 开始菜单首次打开闪现其他背景 | 在隐藏状态抓取当前桌面，新材质异步完成后才映射窗口；相同背景继续复用，快速取消有请求序号守卫 |
| 删除/卸载确认被菜单盖住、按钮下黑框 | 业务确认前收起开始菜单；标准按钮容器显式透明，不影响按钮和输入控件底色 |
| 正常应用可以移除快捷方式 | 移除常规右键入口；启动确实失败后，只为可证明目标程序丢失或不可执行的用户入口提供清理建议 |
| 诊断详情任务栏使用默认图标 | 内嵌监视图标、多尺寸位图、WM_CLASS 与 desktop 身份同时补齐；隐藏的 desktop 条目用于任务栏匹配，不增加应用列表项目 |

UKUI 任务栏会匹配应用身份，因此仅设置 QIcon 不足以修复实际图标。图标选择窗归属 `ukui-fences-settings`，诊断详情归属 `ukui-fences-monitor`。安装同时提供对应 desktop 文件和监视 SVG；用户安装脚本使用实际 launcher 和图标绝对路径。桌面画布身份保留。

诊断窗口显式开启透明表面，绘制前清除旧背景，准备材质前使用圆角回退；避免不透明回退残留在圆角。公共标题按钮从宿主当前调色板读取前景，保证宿主更新明暗模式后仍可辨认。

## 启动失败与清理边界

启动在独立短进程中调用 GLib DesktopAppInfo，读取真实桌面文件，保留 Exec 引号、字段参数、Terminal 与 D-Bus 激活。兼容本机没有 `gio launch` 子命令的旧 GIO。启动成功后才记录使用；接口错误、无法启动和超时有单次结果保护。

只有明确失败且当前用户桌面文件指向不存在/不可执行的程序时才建议清理。系统入口、符号链接、D-Bus 激活、相对路径及不能明确判断的包装命令保守保留。确认默认“不移除”；确认后再次检查入口内容与目标状态，修复或修改过的入口不删除。清理只移除失效 desktop 文件及其固定记录。

## 验证与本机更新

本轮 **42 个不同的相关 CTest 入口最终通过**：Fences/公共组件 30 项、开始菜单 6 项、任务栏 6 项。最终代码另复测受影响的共享弹窗、设置中心、图标选择和诊断共 16 项，以及中文带空格的真实启动/失败流程三档缩放；均通过。不是全仓所有历史测试的结论。

覆盖 UKUI 原生样式与 Fusion、100%/125%/150%/200% 缩放、父窗口置顶、按钮行空白像素与玻璃参考一致、原生任务身份、透明圆角、明暗可读性、取消卸载、真实启动 helper、默认保留失效入口、修复后拒绝清理、旧查询收件人销毁、首帧等待、快速取消和桌面背景变化。修正了原有取样落在透明圆角处的固定物理像素断言，改查按 DPR 换算的内部背景；并保留角落透明度断言。没有卸载实际软件、删除用户快捷方式或发送诊断 API 请求。

本机图标选择窗已验证直接获得焦点并在设置中心之上显示；任务栏实际显示专用监视图标。诊断标题最小化后、显示桌面后，均可通过真实任务栏点击恢复并获得焦点，探针窗口随后正常关闭。KWin 的“显示桌面”不一定把客户端 WM_STATE 改为 Iconic，因此实际验证依据显示桌面状态、真实点击和恢复后的焦点，而非仅依赖隐藏标志。

新进程首次打开录制了两秒、30 fps 的视频，逐帧检查没有观察到系统壁纸背景；隔离用例同时验证首次和变化后抓取的是可见桌面窗口。录屏有时间分辨率限制，不承诺所有硬件任意瞬间都无异常。光学参数、缓存和事件驱动高光保持原实现，没有新增轮询或持续抓屏。

三个宿主已备份、安装和重新加载，两个运行二进制及面板映射插件与构建一致；设置、布局、小组件几何及可见性、系统监视参数、任务栏和开始按钮几何在部署检查中保留。任务身份资源同时安装。`git diff --check`、安装脚本语法与 desktop 文件验证通过。
