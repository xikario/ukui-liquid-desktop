# 源码收录范围

2026-09-28 以当前磁盘工作源码重新整理，覆盖六个当前液态桌面模块。初始候选为 181 个文件（约 3.41 MiB），包含 C++/Python/脚本、测试、图标、shader、2026 节假日资源、打包入口和模块文档；另补充本仓库 README、许可证及构建安装说明。

## 主线选择

- 开始菜单使用 V2 工作树。
- Fences 使用近期运行版本对应的 v0.4.0 工作树，包含四个新增小组件、音乐音符更新和日历年月滚轮。
- 历史 `ukui-fences-git` 整理树缺少近期功能，并含独立的未合入进程诊断修改；没有将它覆盖进液态主线，其本地原件保留。旧开始菜单和独立 panel 原型亦不作为当前主线。
- 上游仅收录实际使用的 shader、参考来源说明及许可证；不重复上传研究用的完整上游 clone。

因此“完整”指当前六模块的完整可构建源码与资源，不是整台机器、所有历史版本或个人数据的镜像。

## 发布副本调整

- 依据 `apps/` + `shared/` 的新目录结构，修正开始菜单和面板的 CMake 相对路径。
- 去掉开始菜单自启动模板中的本机绝对路径，提供显式 CMake 安装规则；启动器支持已安装二进制及开发构建回退。
- Fences 安装脚本默认构建目录统一为 `build`。
- 开始按钮回归脚本支持环境变量指定待测二进制。
- 文档按当前源码修正，旧测试/交付说明标注为历史；删除本机路径和私人文件名。设计原型仍保留，并标明不参与构建。
- 保留第三方许可；新增根 GPL 正文、忽略规则、架构和安装说明。

应用运行逻辑、当前音乐渲染源码及测试保留工作树内容；整理过程不替换本机已安装程序、不改用户配置、不重启桌面。

## 不入库

构建目录、SDK、二进制、压缩包、日志、临时修改脚本、源码备份、部署备份、个人配置、API 凭据、文件索引、知识库、活动统计、系统日历/待办数据库、曲库以及真实桌面截图均不收录。资源图片只保留程序图标及图标预览。

`SOURCE_MANIFEST.sha256` 记录首次发布时的源码与资源校验和（不包含它自身、验证报告与根目录文档）。可在仓库根目录执行 `sha256sum -c docs/SOURCE_MANIFEST.sha256` 检查。
