### 首次发布复测记录与限制

开始按钮旧测试用例把 150% 面板几何写进坐标断言。直接继承宿主环境及设为 100% 的两次运行未通过该坐标断言；按用例设计固定 `QT_FONT_DPI=96 QT_SCALE_FACTOR=1.5 QT_SCREEN_SCALE_FACTORS=1` 后全部通过。没有为此改动生产按钮逻辑；BUILD.md 已明确测试环境。

Xvfb 的 Fences GPU 用例是跳过而不是通过；另在真实显示器的离屏 GL context 中补测三套渲染器，未创建桌面主窗口、未替换运行程序。

没有执行全部历史 UI 脚本、资源压力测试、系统面板 OEM 冒烟或整机重启。部分历史智能空间脚本仍预期旧多空间/AI 功能，之前已有基线不通过记录，参见模块的 FENCE_LIQUID_GLASS.md。不得把所选回归写成全仓测试全部通过。

真实 GPU 检查验证光学结果及缓存，不承诺其他显卡、其他 OEM 面板版本或首次动画帧率。上传操作不部署新二进制、不改变当前桌面设置。
