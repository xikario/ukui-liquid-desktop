## 后台任务退出生命周期

`BackgroundTask` 在应用线程登记活动任务。`aboutToQuit` 及应用入口的 RAII 守卫停止提交新任务、发出中断请求，运行事件循环直到工作结束，并等待线程局部析构完成，然后才允许应用状态销毁。退出期间不交付业务回调；接收者销毁仍自动取消完成回调。所有工作函数继续要求只捕获值。

文件批处理在项目之间响应中断，当前文件操作保持完整性。不会强行终止 QThread。阻塞的底层文件系统 I/O 仍须完成后才能安全退出；等待期间事件、绘制和定时器继续处理，用户输入不进入退出阶段的嵌套循环。
