# 设置中心与小组件视觉修订（2026-09-30）

## 本次处理

1. 移除设置中的“液态气泡预览”及无引用启动方法；共享开发预览工具不作为用户设置入口。
2. Fences 应用范围使用 Qt 的 `AA_DontShowIconsInMenus`，隐藏右键动作装饰图标，保留状态对号与子菜单箭头。其他应用不受影响。
3. 桌面重申层级时取消直接抬升 X11 根框架：Fences 位于 Peony 桌面之上、普通应用窗口之下。最终反馈修订中，设置使用独立置顶窗口，避免外部点击后被遮挡；仍可主动最小化与关闭。
4. 智能空间设置的全部标签页与滚动区透明；局部标签样式改为 Fusion，避免 UKUI `DefaultSlideAnimator` 生成带白底的临时页面。最终验证采集的是切换过程的整窗画面，不能仅检查原始 page widget。
5. 设置背景最终采用打开时一次性捕获，以原生 DPR 渲染后释放光学渲染器；拖动、缩放、换壁纸均复用缓存，关闭重开才更新。取消实时拖动取样，以消除用户反馈的拖动眩晕与卡顿。
6. 设置恢复普通 QComboBox 下拉列表和 QSpinBox 微调按钮。`SettingsComboPopup` 仅接管下拉背景，打开时取一次壁纸生成液态材质，保留 Qt 模型、滚动、键盘和选择机制。`LiquidWheelPicker` 仅供日历年月使用。深色样式/调色板移至内容容器，文件选择器以未染色的顶层窗口为父窗口，沿用系统默认外观。
7. 时钟只在镜片缓存更新时采样亮度；浅底使用深色刻度、数字、指针和倒计时，深底使用浅色。细描边改善混合背景上的识别，时钟滴答不重建镜片。
8. 音乐音符覆盖进度条上方整片区域，数量 6→5，速度略放缓、透明度略降低。仍只在可见且播放中以约 30fps 更新音符区域，不重建背景；暂停/隐藏/播放器退出立即停止。

9. 桌面分区开合捕获一次完整展开快照，约 200ms 揭示/收回，快速反向点击复用同一快照；动画期间不重排图标、不重建光学材质，完成或编辑中断时释放缓存并恢复交互、轮廓与布局。展开高度及保存逻辑保留。
10. 任务栏中断来自并行 MusicFox 安装任务停止/重启 ukui-panel 后的启动空档，已恢复液态任务栏；本次未发现壁纸切换导致面板崩溃的证据，未改动面板源代码。

## 早期性能测量（实时拖动方案已取消）

在本机真实 GPU 上，对 1020×730 逻辑尺寸设置背景、已缓存扩散材质执行 15 次位置变化：

| 光学取样 DPR | 平均单次光学渲染 |
| --- | --- |
| 1.5 | 73.7ms |
| 1.0 | 30.5ms |
| 0.75 | 19.1ms |
| 0.5 | 9.2ms |

早期方案采用 0.75 保留材质细节，之后另有原生圆角合成开销。最终版本不再执行拖动时的背景渲染。这是独立背景渲染测量，不代表整个桌面的帧率或 CPU/GPU 占用率。首次创建着色器的准备时间约 0.6–0.7 秒，只发生在窗口第一次准备时；最终版本只在打开时计算一次，之后释放渲染器。
