# 任务栏材质设置与开始菜单公共渲染（2026-09-29）

## 实现

任务栏新增背景清晰度、液态强度、后窗透视开关及程度设置。旧压暗、色彩、圆角、高光和折射基线保留；新默认值为清晰度 0%、强度 100%、透视关闭（开启后初值 35%）。设置即时保存。透明度只乘到底板绘制，子控件的窗口透明度不变；原生轮廓继续使用未经透明度衰减的抗锯齿覆盖，避免圆角收缩或矩形模糊露边。

公共 `LiquidOpticsRenderer` 增加默认兼容的材质参数及控件模式。默认参数不改变已有算法；非默认清晰度混入原始纹理，强度调节光学边缘范围与折射位移；CPU 回退提供简化边缘弯折。控件从主体材质取样，不重复压暗背景。

开始菜单此前默认使用 CPU 简化材质；旧 GPU 路径还将画面缩到 0.67 倍再放大。现在默认使用公共全分辨率 Snell 材质，控件也复用公共着色器，删除重复 GPU 实现。主体保留扩散保障阅读，增强边缘高光及弯折。隐藏启动时一次性用 64×64 合成图预热两个渲染器，不截屏、不显示合成图；明确选择 FAST/NO_GL 时不预热。仍保留 GPU 不可用时的 CPU 回退、相同背景比较和有界控件缓存。

任务栏设置仍只控制任务栏进程；本轮没有新增跨应用参数同步。透视由合成器显示后方窗口，不是对后方窗口实时折射；没有新增持续截图、刷新定时器或 KWin 模糊请求。

## 性能范围

独立 GPU 渲染用例的首次合成图预热约 916 ms；实际进程启动预热约 931 ms，发生在隐藏启动阶段。实际首次打开的主体材质渲染记录 106 ms；五次暖渲染均值约 60.6 ms（1020×1080 物理像素），CPU 快速路径一次测得 31 ms。以上不含完整交互链路，不能据此承诺零首次延迟或固定帧率。效果增强仍有单次渲染成本，但没有增加空闲渲染循环。

关闭设置窗口及开始菜单后，10 秒进程增量采样：任务栏 CPU 约 0.2%、RSS 91.1 MiB；开始菜单 CPU 约 0.4%、RSS 148.9 MiB。CPU 按单核 100% 计。这是短时观察，不是长期压力测试，也没有测得 GPU 利用率。

## 后续修复：清晰度与强度看起来无效

用户实测两个滑块没有明显变化。复查发现当前系统壁纸虽然使用 `.png` 扩展名，实际内容是 JPEG。`WallpaperBackdrop` 的 `QImage(path)` 解码失败，任务栏进入 `LiquidSurface` 备用底板；该路径不使用清晰度和折射强度，因此设置会保存，但没有对应的光学变化。Fences 已使用按内容识别的加载器，所以桌面壁纸仍然正常。此前人工检查确认了插件加载和设置界面，却未确认该壁纸实际进入 Snell 路径；正常格式图片的测试无法覆盖这个问题。

改为 `QImageReader::setDecideFormatFromContent(true)`，同时采用与 Fences 一致的 EXIF 自动方向；解码失败记录明确日志。没有改变壁纸文件、材质参数或用户设置，也没有通过增强着色器掩盖加载问题。

新增中文路径、PNG 扩展名/JPEG 内容的回归，检查非空裁剪、真实像素和重复读取缓存。选定回归 3/3 通过（面板交互、CPU 光学回退、150% 原生圆角）；真实 GPU 光学检查 43 项断言通过。使用当前系统壁纸离屏比较清晰度和强度的端点输出，确认纹理清晰度与边缘弯折实际改变。
