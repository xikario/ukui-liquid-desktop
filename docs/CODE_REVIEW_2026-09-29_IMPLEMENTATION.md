# 2026-09-29 审查整改实施记录

本轮以 `5633e7e` 为基线，落实[逐项核查报告](CODE_REVIEW_2026-09-29_VERIFICATION.md)中确认存在的问题。核查文档描述的是修改前状态，本文记录后续实施。

## 已实施

- **文件任务统一**：桌面、分区、文件夹图标的外部拖放、粘贴、回收站、永久删除和撤销操作复用后台文件任务入口。一次执行一个任务；复制/拖放支持在项目之间取消，已提交的目标保留，失败或取消的剪切项目保留在剪贴板。重名、自复制、跨文件系统复制后再删除源文件等保护继续有效。组件销毁后不再投递 UI 回调。正常退出入口在文件任务运行时提示稍后退出，不再无限等待线程，也不直接打断文件提交。
- **目录详情按需加载**：创建图标不再列举子项或递归统计；悬停 300ms 后后台查询。最多两个并发查询，按遍历项数和可检查的时间预算截断，详情缓存 30 秒；切换图标路径时清除旧详情。底层文件系统单次阻塞 I/O 不能由普通取消标志强制中断，限制的是遍历任务数量和后续工作量。
- **打开方式与开始菜单**：MIME 应用查询、安装来源和卸载影响查询移至后台。开始菜单合并文件监视事件，后台解析 `.desktop`，仅应用最新结果；主线程继续创建控件和图标。活动窗口查询复用事件监听的 X11 连接，任务栏原生属性操作复用同线程连接。
- **系统监视**：普通刷新和诊断采样采用不重叠的后台采集任务，采样数据与控件更新分开；保留隐藏/紧凑模式节流，诊断与普通采样的历史基线分开。AI 请求启动改为信号驱动，保留用户主动触发和 HTTPS 限制；本次测试没有发送真实 AI 请求。
- **壁纸与材质**：桌面、任务栏的配置读取和图片解码移至后台，过期结果丢弃；开始菜单壁纸取色也不再等待 gsettings。Fences 的整屏模糊预处理移至后台，完成后统一失效分区缓存。三处光学适配器复用 `LiquidMaterial.h`，采用滑动求和并保留原有逐像素结果。保留现有 shader、折射参数、CPU 回退及 Peony 兼容方案。
- **气泡与定位**：同一个气泡收起途中重新打开时延续动画进度和材质；不同内容重新生成。增加按需开启的截图/材质阶段计时。任务栏检测通过 RandR 的原生屏幕坐标映射到 Qt 逻辑坐标，strut 降级只接受 ukui-panel，处理副屏偏移与包含末端像素的范围；无法可靠映射多屏时不猜测坐标。
- **最近记录**：XBEL 改为读取属性、正确解码本地 URL、按修改时间排序后截取。当前实际使用的时间文案按本地日期区分“昨天”和“几天前”。
- **退出与重绘缺陷**：回归中发现 `DesktopIcon` 子 QProcess 析构可能回调已析构的图标成员，已在成员销毁前断开并停止相关子进程；系统监视作相同保护。图标缩放结果进入有容量限制的 QPixmapCache，避免 Qt 在局部裁剪重绘时再次缩放产生边缘颜色差异，继续局部重绘。
- **CI**：保留现有 Fences 流水线，新增开始菜单和任务栏构建/测试任务，加入异步生命周期、材质一致性和元数据测试。没有把本机结果当成远端 GitHub Actions 已通过。

| CPU 预处理 | P50 | P95（9 个样本中取最高值） |
|---|---:|---:|
| 原实现 | 596ms | 612ms |
| 公共滑动求和实现 | 408ms | 424ms |

重现基准：构建 `liquid-material-test` 后，以 `UKUI_LIQUID_MATERIAL_BENCHMARK=1` 启动。气泡阶段计时以 `UKUI_LIQUID_POPUP_PROFILE=1` 开启，默认关闭，不增加常驻采样定时器。离屏气泡测试使用合成背景/provider，其截图耗时不能当成真实 Xorg 截图成本。
