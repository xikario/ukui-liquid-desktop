## 验证方法与结果

核对应用入口、启动包装器、CMake 安装规则、实际菜单和表单标签、知识库 argparse 参数、MPRIS 选择/启动逻辑、渲染器接口及安装恢复脚本。未对外部服务可用性、所有硬件或全部历史代码作完整评审。

执行的隔离检查：面板安装事务 10 项、登录检查 4 项、Peony 范围 2 项、FTG340 策略 2 项、智能空间知识库 3 项、文件索引 23 项、日历只读快照 4 项，共 **48 项 Python 单元测试通过**。Peony X11 事件回归的 23 项检查另行通过。所有测试使用临时目录、替身工具或独立 Xvfb，不运行真实安装、卸载或调频。

知识库主命令/build/search 及索引器的 --help 与文档参数一致。20 份 Markdown 的 **146 个本地链接/锚点、34 段 shell 命令语法**检查通过；git diff --check 通过。链接检查覆盖本轮修改和新增的当前指南，不把未收录的历史产物当作可访问链接。

本轮未重新构建或部署二进制、未重跑全仓 UI/GPU 测试，也未调用真实诊断 API；原 v0.5.1 功能验证仍见 [版本记录](versions/v0.5.1.md)。带日期的旧设计/部署记录保留历史含义，最新使用说明以产品首页及其操作指南为准。
