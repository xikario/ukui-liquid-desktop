# 分区拖动排序与实验性视频标识

壁纸类型选项改为“视频壁纸（实验性）”。选择视频时持续显示说明：可能增加 CPU/GPU 占用、发热和风扇噪声，启动/切换可能短暂显示静态画面，需要安静省电时建议静态图片。说明与操作状态分开，不会在应用成功或错误后消失。

分区内拖动文件或文件夹时，优先解释为顺序调整，包含落在另一个文件夹图标上的情况。停留约 180 ms 后确认插入位置，周围图标在 160 ms 内滑动让位，拖动项留出空位。悬停只更新显示，不更改已保存的顺序或文件路径；松手后更新顺序并沿用布局保存信号，Esc、拖出分区和文件列表变化会取消预览。支持多选、跨行与滚动位置，移动多项时保留相对次序。

原地松手的失败提示来自目录图标接收自身路径后进入文件夹传输流程。同分区现在走排序路径，桌面散放目录也会识别“拖到自己”，作为无操作接受，不启动文件任务、弹进度或错误。真正的文件传输失败提示保留。跨分区或外部文件拖到目录仍按原来的目录传输/撤销处理；同一分区内若需把文件移入目录，可以剪切后进入目录粘贴。

顺便修正多选向后插入的索引：扣除目标位置之前的拖动项时以原始目标为基准，避免边扣除边比较导致相邻多选错位。

预览动画仅拖动时运行，不添加常驻刷新。图标删除、分区排序或列表加入项目时清理预览，避免过期指针和撤销后保存临时顺序。
