# 代码审阅与液态图标落地（2026-09-29）

依据用户的《代码分析和液态图标.txt》核对实际源码。文档中的风险假设不直接视为已确认漏洞。

## 本次实施

- 新增独立 `LiquidIconRenderer`，原图标来源与主题保持原样。玻璃底座使用渐变、弱壁纸染色、圆角边缘与阴影的缓存绘制；不使用每帧抓屏、卷积或持续刷新定时器。
- 默认桌面底座开启、分区内部关闭；后者开启后材质强度乘 0.65。默认强度 62%，图标内容为原尺寸的 82%；底座、阴影和文字布局随缩放调整。
- `外观与特效 → 桌面图标样式…` 提供原始/液态、强度、跟随壁纸/中性和分区内部开关。应用立即刷新，取消未应用修改不生效。QSettings 持久化，与布局文件分离。
- 所有创建路径与单项、多项、系统图标拖拽统一使用底座；剪切同时降低底座和图标的不透明度。原生图标仅进行缩放，保持颜色与清晰度。
- 菜单代理样式限于液态 QMenu，保留 QApplication 原有样式；环境关闭开关覆盖 glyph 接入。菜单销毁时只恢复仍存活的外部 QAction，不在 QObject 析构期访问已经析构的 QWidget。
- 新增 1×/1.5×/2× 实际菜单、图标和设置持久化回归。截图等待连续非空帧并有超时，减少单次固定延时捕获空帧的问题；这不取代功能状态断言。
- 壁纸按内容解码，按显示需求缩放，提供路径、修改/元数据时间、大小、目标尺寸组成的单项缓存；平铺和居中模式保留原始像素尺寸。超过一亿像素拒绝，错误信息可见。解码仍在主线程，PNG 等格式的内部解码内存受插件实现影响，缓存不等于零内存成本。
- 桌面与分区的粘贴在工作线程执行，GUI 线程负责剪贴板、进度及落位；并行粘贴串行化，完成后不覆盖用户新复制的内容。复制先暂存再发布；同名目标拒绝覆盖，禁止递归复制到自身。gio/rename 失败后尝试复制再删除源目录，复制失败保留源；删除源失败可能留下目标副本和部分源目录并报告失败。拖放、删除和撤销仍有同步调用，未宣称文件管理全部异步化。
- 修复隐藏文件冲突时重复后缀，保留目录与符号链接保护。D-Bus 注册/转发失败返回非零并输出原因。
- AI 请求仅允许 HTTPS，curl 限制协议；provider 携带 Authorization、Cookie 或 API Key 时拒绝 HTTP，带凭据请求不自动重定向，避免凭据被转发。
- 增加 Ubuntu CPU/Xvfb GitHub Actions，覆盖构建、Python、菜单、图标和粘贴回归。Ubuntu 不等同 UKUI 真机，不覆盖真实 GPU/窗口管理器与系统密钥环全部行为。

## 核对结论及保留项

| 原分析 | 核对结果与处理 |
| --- | --- |
| AI 自动上传、shell 注入、完整命令行外发 | `beginDiagnosis` 由交互触发；curl 使用独立参数及 stdin；`diagnosticTelemetry` 显式构建字段，没有完整命令行/可执行文件路径。单进程诊断包含 PID、父 PID、进程名和资源统计。不是已确认的上述三类漏洞。|
| QNetworkAccessManager 替换 curl | 有价值，但属于网络客户端重构。本轮保留已有超时/凭据保护，先限制 HTTPS；不改变用户模型与密钥配置。|
| command provider 任意执行 | 属于用户显式配置的本地插件能力；没有查到“主题导入即执行”链路。配置及 inheritFrom 文件必须可信，文档补充说明。暂不增加会破坏已有 provider 的全局白名单。|
| 所有跨设备 rename 必然失败 | 目录回退存在缺口；QFile::rename 对文件可自行复制，原分析表述过宽。本轮增加一致的目录回退与失败保护。|
| 主目录磁盘与根目录文案 | 已将 README 改成主目录所在分区。|
| CLI 枚举化、冲突计数复杂度 | 计数类型扩为 quint64；枚举化是可维护性建议，没有改写已稳定的命令优先级。D-Bus 注册窗口仍可能导致极早启动的第二次请求失败，但现在明确返回错误。|
| 巨型文件、采集线程化、配置总线 | 合理的后续工程：本轮先抽离图标渲染和设置，不同时改造监控/索引/跨应用生命周期。|
| 全局按键 XRecord | 位于开始菜单组件，应独立审查 ABI 与键盘行为。直接换 XGrabKey 会影响 Super 组合键，不能据方案片段直接替换。|
| 国际化、依赖自检、默认厂商标题、模型标签 | 属于产品与兼容性改造；目前模型载荷确实固定 DeepSeek V4 Flash，标签并非与当前载荷不符。保留用户已有标题。|
| 日历 2026 数据、os.tsx | 已有年份范围文档；后续增加按实际数据覆盖范围的 UI 提示。设计参考文件暂保留，避免未经核对删除。|
| 字体对比度 | 保留用户字体；半透明材质的实际对比度取决于每个文字区域，不能仅据壁纸主色判断。本轮不增加错误提示。|

## 验证边界

真实系统只安装并重启 Fences。公共模块源码修改不会自动替换其他已静态链接的应用，需要各应用后续重建。测试记录见 Fences 的 `docs/SMART_SPACE_TEST_REPORT.md`。没有进行整机重启，也没有执行真实 AI 外发请求。
