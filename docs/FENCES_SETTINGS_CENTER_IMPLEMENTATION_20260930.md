# Fences 统一设置中心实施（2026-09-30）

## 入口与页面

- 右键根菜单保留新建、粘贴、撤销、刷新、编辑模式、排列方式、小组件显示；“打开文件管理器”紧接“刷新桌面”。
- 原“外观与特效”“设置与帮助”合并为 **Fences 设置…**。
- 左侧分类、右侧滚动设置；单窗口实例，记住最后页面，支持拖动、右下角缩放、最小化、Escape 关闭。
- 壁纸选择/预览/模式、主题取色/预设/外部主题、图标底座与字体、网格、分区锁定/颜色/透明度/图标/标题和内部字体、布局导入导出/重置、文件收纳、使用说明/来源许可全部可从中心操作。
- 六组件独立配置导航；系统监视与智能空间的完整配置表单在右侧，不再从此处弹出旧设置框。播放与倒计时保留在组件本体；日历折叠/数据同步、活动记录设置集中可达。
- 单组件显示与自启动分开呈现“已开启/未开启”。系统监视/智能空间的旧专项自启动复选框移除，避免旧表单覆盖总览的新值。

## 配置及生命周期

原有表单提取为 QWidget 工厂，以值捕获控件、共享草稿对象和表单生命周期上下文替代模态函数的局部变量引用。复用原保存路径、校验、密钥环和业务方法，不引入重复配置文件。

外观即时开关直接应用；字体/网格/壁纸/复杂组件表单按“应用/保存设置”提交。切换页保留未应用草稿；关闭窗口可取消或明确放弃，窗口销毁释放所有表单。组件在外部被移除时同时销毁其表单，避免引用已删除模型。分区字体右键入口路由到本窗口对应分区页。

隐藏的智能空间/监视页先显示启用按钮，不创建临时组件，不启动采样/索引。需要编辑时由用户明确启用组件。这一版没有另外复制离线业务模型；其余启动状态及四个小组件现有本地配置可以直接管理。

智能空间皮肤不再在未保存时临时应用；校验失败仍保留当前表单。同步麒麟索引目录改为异步 D-Bus 调用。系统监视 API Key 仅在用户实际编辑后才更新，避免密钥环异步读取期间应用其他字段误覆盖密钥。

## 液态与资源

窗口使用 `shared/liquid-glass/LiquidOpticsRenderer` 和 `DesktopCanvas::wallpaperBackdrop`。按最终用户反馈，打开时以原生 DPR 取一次壁纸材质并释放渲染器，存续期间固定。移动/缩放/换壁纸不重算，关闭后重新打开才更新。无持续渲染定时器，不采集其他应用；这是壁纸材质。设置窗口置顶但仍支持主动最小化与关闭。下拉为普通 Qt 列表加液态背景，数字为普通微调框，日历年月滚轮保留。样式只施加到内容区，原生系统文件对话框通过未染色的顶层窗口打开。

设置窗口是独立正常窗口，不纳入桌面组件磁吸、图标避让与组件位置持久化。关闭释放窗口及光学渲染器，不留下常驻绘制。
