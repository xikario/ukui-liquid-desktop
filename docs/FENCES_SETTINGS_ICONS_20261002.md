# 分区设置合并与系统标题图标（2026-10-02）

本轮把分区右键散落的外观入口收进已有设置中心，增加清除图标确认，并接入系统图标库。沿用公共液态对话框、折射材质和有限开关动画，不新增驻留服务。

## 开始菜单与任务栏的覆盖核验

上一轮公共弹窗更新覆盖了 Fences、开始菜单设置及消息、任务栏主题设置及 Provider 编辑。本轮开始时核对了真实进程：Fences 和开始菜单的运行二进制与上一轮部署记录完全一致，任务栏加载的插件路径及文件哈希也与部署记录一致。开始菜单主面板的外观没有因这轮公共对话框接入发生变化。

本轮新增产品功能属于 Fences；没有再次修改或重启开始菜单与任务栏。

## 用户入口

- 分区标题栏或分区内容空白处右键 → **分区设置…**，直接打开对应分区的设置页。
- 也可从 **Fences 设置 → 分区与布局 → 分区名称 · 分区设置** 进入。
- 名称、颜色、不透明度、锁定、标题图标、标题字体和内部图标字体集中显示。重命名、折叠、锁定、排序与文件操作保留快捷入口。
- **清除分区图标…** 明确询问是否清除标题图标，默认取消。确认只改变图标选择，不移除分区或操作文件；未设置图标时沿用原小框占位。
- 标题图标提供 **系统图标库**、**内置默认图标**、**图片文件** 三种来源。十个默认 SVG 已嵌入二进制，新建分区无需依赖外部资源目录。

系统图标按名称保存到布局的 `titleIconTheme`，由 Qt 根据当前主题解析，切换主题后跟随变化；缺失名称暂时使用内置图标兜底。文件及内置资源沿用 `titleIcon`，两种字段互斥。旧图片路径和旧布局中已清除的选择保持兼容。

## 资源与交互处理

只在访问系统图标页时读取目录，在已有后台任务框架中扫描当前主题、继承主题、hicolor 和 Qt 兜底目录。按名称合并不同尺寸；主线程只在列表实际绘制时取图标。没有静止轮询，搜索以 100 ms 单次计时合并输入，退出会取消未完成的读取并丢弃已销毁窗口的回调。

主题目录及继承按照 [Freedesktop 图标主题规范](https://specifications.freedesktop.org/icon-theme/latest/) 读取；图标的实际查找和主题切换交给 `QIcon::fromTheme`。

图标页使用设置中心已有的局部标签样式，消除 UKUI 滑动快照露出的白底。固定图标单元格保留完整默认名称，系统长名称可查看提示。点击确定时先固定已选项，再开始关闭动画；未完成的搜索不能把接受结果变成空选择。
