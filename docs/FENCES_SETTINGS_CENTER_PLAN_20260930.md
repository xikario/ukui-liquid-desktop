# Fences 统一设置中心：源码核查与实施计划

日期：2026-09-30。状态：方案已获授权，实施见 `FENCES_SETTINGS_CENTER_IMPLEMENTATION_20260930.md`。本次另行落实小组件缩放磁吸，二者可独立交付。

## 1. 结论与入口

可行，现有 Qt 5 Widgets 和共享液态材质足以实现。主要工作是把当前对话框里混在一起的界面、读配置、应用配置拆开，复用同一份状态；不能仅将现有模态对话框塞进容器。

桌面右键将“外观与特效”“设置与帮助”合为 **Fences 设置…**，直接打开一个独立、可移动、可缩放的非模态窗口。重复点击激活已有窗口，记住最后访问的页面。

保留日常入口：新建、粘贴、撤销、刷新、打开文件管理器（紧随刷新下方）、编辑分区布局／退出布局编辑、排列与布局、桌面小组件。排列与布局保留排序等快捷操作；网格、布局导入导出和重置等配置迁入设置中心。六个组件的显示菜单作为快捷操作保留，状态和设置中心一致。编辑模式仍是显式开关，不因打开设置窗口而启用。

组件右键保留播放、倒计时、更新索引、同步节假日、隐藏等当前对象操作；“设置”跳转中心对应页。分区重命名、锁定等快捷操作保留，字体等配置也可从中心选中该分区修改。

## 2. 左侧导航与右侧内容

默认约 940×660 逻辑像素，左栏约 184；根据屏幕可用区域缩小，右侧内容独立滚动。首次打开“液态外观”，以后恢复上次页面。

| 左侧页面 | 右侧内容 | 迁移来源／范围 |
|---|---|---|
| 液态外观 | 分区液态玻璃开关、材质示例、已有材质能力的参数、气泡预览与刷新 | 现有分区液态开关、共享渲染器、液态气泡预览；新增参数须先明确接收方，不能只添加无效滑块 |
| 壁纸与配色 | 跟随系统／自定义图片、适应方式、当前路径、预览、壁纸取色、内置配色、外部主题文件 | `showWallpaperDialog`、`applyWallpaperThemeToFences`、主题预设与外部主题应用 |
| 图标与文字 | 桌面与分区图标底座、液态强度、壁纸染色、字体族／字号／颜色／粗斜体、实时示例 | `showIconAppearanceDialog`、`showSettingsDialog`；明确“桌面默认”与单个分区覆盖 |
| 分区与布局 | 网格与排列、壁纸磁性画线、分区列表及单项字体/锁定配置、布局导入导出与重置、进入编辑模式 | `showGridDialog`、`FenceWidget` 局部配置、布局菜单；“壁纸磁性画线”与组件矩形边缘磁吸分开命名 |
| 桌面小组件 | 六项总览，每行“当前显示”“随 Fences 启动”两个明确状态；选中组件进入专属配置 | 现有显示/自启方法及各组件设置，统一状态来源 |
| 文件同步 | 新文件默认收纳分区、同步规则说明、手动刷新 | `showDesktopSyncSettingsDialog`；保持现有文件移动/撤销语义 |
| 帮助与维护 | 使用说明、快捷键、版本、上游来源与许可、配置路径、打开文件管理器、返回系统桌面、退出 Fences | 现有帮助/关于/Peony/系统桌面/退出入口；危险操作单独呈现并保留原确认和忙碌保护 |

“桌面小组件”内可展开六个子页，避免把一长串组件配置堆在同一屏：

- 智能空间：现有索引范围、文件格式、更新策略、外观、知识库、Skill、数据源配置；保留显式“立即更新/构建”，浏览页面不触发扫描。
- 系统监视：皮肤、标题、字体、透明度、采样周期、现有高级美化、AI Endpoint／密钥环配置；只有执行诊断才发请求。
- 时钟与倒计时：当前已有可配置项和组件预览；开始/暂停/取消仍在组件本体。
- 活动统计：记录状态和现有统计配置；清除记录仍需确认。
- Strawberry 音乐：已有显示/播放器配置及连接状态；播放控件仍在组件本体。
- 日历与待办：已有待办展开状态、节假日数据更新时间、同步按钮；保持系统待办只读。

后四项只迁移实际存在的配置与操作，不为了填充页面虚构开关。自启动只在组件总览维护一处，子页可显示同一状态或返回总览，避免再次出现重复“启用”开关。

## 3. 液态窗口的视觉与资源方案

主窗口采用统一圆角玻璃底板，左栏轻微加深，当前页有清晰选中态；右侧用少量半透明内容卡片保障文字对比度。玻璃折射、高光和圆角算法复用 `shared/liquid-glass`，菜单/提示复用 `shared/liquid-popup`；不另造一套 shader。

材质默认采样壁纸并缓存，打开、换壁纸、DPR 变化以及窗口移动/缩放结束后更新。拖动/缩放过程中复用上一帧材质并合并更新，禁止逐帧截图、逐帧重建整窗折射或持续运行渲染定时器。按钮悬停只刷新控件局部区域。低资源约束针对 CPU/GPU 和交互卡顿；本次不以压缩内存为目标。

“壁纸液态”不等于“透视后面的实时应用”。首版使用稳定的壁纸材质；如果后续增加实时透视，必须单独研究 KWin 的模糊/透明区域和遮挡，明确其额外开销，不能用壁纸透明度冒充该功能。

正常窗口生命周期与智能空间贴边动画分离：可 Alt+Tab、可关闭、正确获取焦点，不设成 ToolTip/Popup，不随桌面布局保存，也不成为磁吸/图标避让对象。避免设置窗口自身被截入背景。圆角使用带 alpha 的抗锯齿图像，不用整数矩形遮罩切边；验证 DPR 1/1.5/2。

`LiquidSurface` 是持久面板的透明表面辅助，`LiquidPopup` 负责弹出菜单；两者不能直接替代完整设置窗口。可新增 `LiquidSettingsWindow` 外壳，背景由 `LiquidOpticsRenderer` 提供，具体设置控件仍采用 Qt 原生可访问控件。

## 4. 源码落点与状态原则

当前入口集中在 `apps/ukui-fences/src/DesktopCanvas.cpp::contextMenuEvent`。字体、壁纸、网格、同步对话框也在此；图标外观在 `DesktopCanvasIconAppearance.cpp`。智能空间设置集中于 `SmartSpaceWidget::showSettings`，系统监视为 `SystemMonitor::showSettingsDialog`。四个新组件共享 `LiquidDesklet`。

拟新增（此轮不创建生产代码）：

- `FencesSettingsWindow.{h,cpp}`：左侧导航、右侧 `QStackedWidget`、单窗口实例、页跳转、未保存提示。
- `settings/*Page.{h,cpp}`：按需构建各页，控件不负责启动后台业务。
- `FencesSettingsController.{h,cpp}`：统一读写及变更通知；现有 QAction 和页面调用同一入口。
- 共享液态窗口外壳：先确认抽象稳定再放到 `shared/liquid-glass`，避免为单个界面制造过多公共接口。

继续使用现有 `QSettings`、`layout.json`、图标配置与密钥环，不另建一套同义配置文件。保留旧键兼容已有安装；Qt 控件初始化时阻断写回信号，外部修改后同步 UI，避免开窗即覆盖用户配置。

简单开关和视觉调节可立即生效，滑块写盘/重建材质做合并，并提供恢复当前页默认值。复杂目录、Provider、密钥等表单先编辑，再点“应用”；校验失败留在该页，切换/关闭时提示保存或放弃。无隐藏窗口时不创建组件实例以读取设置，避免意外显示、启动采样或扫描。

开始菜单、任务栏、输入法属于独立进程和配置域。该窗口统一的是 Fences 及其承载组件；如果附加其他应用设置快捷入口，明确标注“打开任务栏设置”等，不将其开关伪装为 Fences 总开关。若希望未来统一跨应用材质，应先建立明确的共享参数协议和作用范围。

## 5. 分步实施与验收

1. 提取配置读写和动作，建立来源→页面清单，保持当前入口可用；先覆盖保存/回读、取消、不启动隐藏组件的回归。
2. 完成窗口外壳与液态材质、左栏导航，迁入外观、壁纸、图标、字体、布局、同步页。
3. 迁入六组件总览和复杂专属设置。索引、AI、Provider、密钥环优先保证原语义；迁移期临时按钮只能作为过渡，最终验收要求专项设置在右侧完成。
4. 菜单合并，旧组件“设置”路由到中心对应页，更新帮助路径、截图和自动化测试。
5. 对比开窗前/静止窗口/滑块拖动/窗口缩放/关闭后的 CPU 与材质重建次数；检查无持续后台绘制、无残留窗口。验证重开应用配置恢复；真实重启后再单独验证，不用一次重启应用替代开机验证。

重点验收：旧功能无遗漏、显示与自启动无混淆、壁纸取色不改文字、图片按内容解码、关闭隐藏组件设置不误启动组件、桌面正常拖放和 Ctrl+Z、不影响智能空间动画、系统监视贴边位置、农历同步、音乐与待办状态。

风险最高的是智能空间大对话框的配置/任务耦合，其次是全局主题参数的作用范围。先提取状态，再迁 UI；不直接复制现有弹窗及其局部 lambda，也不把 `exec()` 套进新的右侧页面。
