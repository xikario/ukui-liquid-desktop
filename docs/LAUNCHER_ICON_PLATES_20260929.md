# 开始菜单：单一缓存玻璃图标底座

固定应用、最近应用/列表及侧栏应用统一调用 `drawLauncherIcon`，新增应用沿用同一入口。液态主题下绘制轻薄圆角底座，原生主题只改善图标采样。网格底座约 46 逻辑像素，内部图标保持 38；最近项文字留白调整 3 像素。

开始菜单直接编译 Fences 的 `src/LiquidIconRenderer.cpp`，使用同一份实现，不复制材质代码。底座为缓存的静态渐变、高光和中性色染色，不新增抓屏、着色器、动画或定时器。图标按 DPR 请求实际尺寸并平滑缩放到缓存，物理像素对齐；合法但不报告固定尺寸列表的 SVG 图标不再直接替换为字母图标。

资源边界：首次使用需要生成小图并占用 Qt 有界 QPixmapCache，命中后只贴图；不是零内存或零绘制成本。已有悬停位移和整体玻璃效果保持。未对低分辨率素材进行 AI 重建，也不保证每个应用自带的小图能恢复细节。

验证：开始菜单构建、metadata 回归、diff 空白检查通过。未修改的 Fences 图标渲染器现有外观与 damage 回归覆盖 1×/1.5×/2×；2× 外观用例首次所有断言通过但退出异常，单独复测通过。真实外观由用户打开菜单截图验收。
