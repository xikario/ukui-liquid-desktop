# 智能空间边缘光效与材质缓存 · 2026-10-03

本轮针对用户提出的边缘光效资源开销问题，使用实际 SmartSpaceWidget 和 SystemMonitor 做隔离对比，再修改智能空间绘制。前一轮的主界面融合、结果与预览切换保持。

## 实现

- 去掉智能空间独立的宽边缘光带和弯曲焦散亮纹，改用与系统监视器相同的 112 逻辑像素反光半径、1.6 像素细边和淡色 8 像素内侧辉光。
- 保留距边缘 52 像素内才绘制的条件。鼠标离开边缘时重绘原有覆盖区；边缘以外的内容区移动不重绘光效。
- 壁纸、整体阅读遮罩、静态渐变与外轮廓合成为一张 ARGB 材质缓存。指针帧复用它，仅绘制动态反光；壁纸变化主动失效，尺寸和 DPR 变化自动重建，切换到非液态或嵌入模式释放缓存。
- 保留已有事件驱动和 33 ms 单次帧合并，不新增持续轮询，也不改变收起/展开动画。

缓存以少量内存换取较少的重复绘制：760×450 逻辑像素、150% 缩放下，新增材质图像为 1140×675×4 字节，约 2.94 MiB；不是对整个应用 RSS 增量的测量。

## 测量方法与范围

测试程序新增显式的 `--pointer-benchmark <输出 JSON>` 模式，默认 CTest 不跑性能采样。每次使用独立 Xvfb、会话总线以及临时 HOME/XDG 目录，壁纸为生成的测试图，无真实文件索引，其他小组件关闭。系统监视器的统计和诊断采样计时器停止，以免将采样工作归为光效。

固定 Qt Fusion、96 DPI、150% 缩放，关闭 GL，测量 CPU 光栅绘制。向真实组件发送鼠标移动事件并移动虚拟 X 光标，目标输入约 125 Hz，沿左边缘相同的 100 像素区间往返。每组件分别静止约 2 秒、移动约 8 秒，以进程 CPU 时间除以实际墙钟时间计算单核百分比，同时记录重绘次数和逻辑像素量。

系统监视器使用 720×248 的紧凑尺寸，智能空间为 760×450；前者的指针帧间隔为 16 ms，后者为 33 ms。因此跨组件数字用于说明各自实现的开销，不能解释成相同帧率、相同尺寸下的纯算法胜负。智能空间前后使用相同尺寸、输入和计时逻辑。

初步采样出现 CPU 耗时波动，连未修改的监视器数字也变化；所有 JSON 留在测试产物中。最终使用三组相邻的旧版/新版采样，给出各轮结果，避免把机器运行状态的变化全算为优化收益。它们不包含真实桌面的合成器/GPU 开销、索引、加载大文档或其他应用工作，不能当成长时间日常 CPU 保证。

可复测命令（仓库根目录，先构建 `fence-glass-test`）：

```sh
QT_FONT_DPI=96 QT_STYLE_OVERRIDE=Fusion QT_SCALE_FACTOR=1.5 \
QT_SCREEN_SCALE_FACTORS=1 UKUI_FENCES_GLASS_NO_GL=1 \
xvfb-run -a -s '-screen 0 2560x1600x24' dbus-run-session -- \
apps/ukui-fences/build/fence-glass-test --pointer-benchmark /tmp/smart-edge.json
```

## 相邻对比结果

CPU 为各移动阶段的平均单核百分比。所有静止阶段重绘次数为 0，记录的进程 CPU 约 0.006%～0.008%。

| 采样对 | 智能空间旧版 | 智能空间新版 | 阶段平均 CPU 降幅 | 监视器对照（旧/新测试进程） |
| --- | ---: | ---: | ---: | ---: |
| before-5 / after-1 | 2.66% | 2.17% | 18.3% | 5.86% / 5.96% |
| before-6 / after-4 | 2.76% | 2.15% | 22.3% | 5.64% / 5.65% |
| before-7 / after-5 | 2.63% | 2.04% | 22.5% | 5.00% / 5.69% |

三组智能空间阶段平均 CPU 降幅中位数为 22.3%。帧数与墙钟时间都保存在原始 JSON；测试包含事件投递、边缘绘制和 Qt 运行开销，未直接测 GPU。对照组件也存在波动，因此这里只报告此项短时条件下的结果。

生成的界面截图核对了细边效果及既有底板和文字。初步样本、最终样本、旧版二进制、性能汇总和测试日志位于忽略目录 `apps/ukui-fences/build/artifacts/smart-space-edge-20261003/`。

## 回归验证

`ukui-fences` 和 `fence-glass-test` 构建通过。12 项相关 CTest 全部通过：三种缩放下的指针效果、智能空间交互及贴边定位各 3 项，加上 UI、液态模式、异步启动冒烟。新断言核验边缘事件合并、局部覆盖范围、移动时材质复用、尺寸/壁纸变化后缓存更新、静止后无重绘。

指针测试从屏幕实际 backing 抓取局部更新结果，再与显式完整重绘比较（抗锯齿容差 2/255），覆盖四边、角落、离开边缘及材质刷新，检查残留高光和拖影。前后生成截图的中央静态区域 RGB 逐像素一致，比较记录为 `static-surface-comparison.json`；这不等于所有真实壁纸或 GPU 路径都已穷尽测试。
