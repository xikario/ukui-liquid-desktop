# 图标白底与图片缩略图 · 2026-10-03

系统图标中有大量深色线条、透明背景图标，原深色列表难以辨认。系统图标库和内置默认图标的列表现统一使用不透明白底、深色名称和浅青色选中/悬停状态；搜索框、标签页、窗口壳继续沿用液态材质。

## 图片浏览

公共 `LiquidDialog::getOpenImageName` 使用 Qt 的非原生文件选择器，默认以 96×72 逻辑像素缩略图、148×112 网格浏览图片。Fences 壁纸、分区图片图标和开始菜单自定义图标均已接入，普通文件/目录/保存选择继续使用原入口。

- 缩略图由可见项目的绘制按需请求，没有目录全量图片解码。保留 Qt 文件系统模型、目录导航、文件过滤、键盘/鼠标选择、确认和取消。
- 每个选择器同时仅一个后台解码任务；最多排队 48 项，开始解码前再次检查项目仍然可见，快速滚动不会继续处理离开屏幕的排队图片。
- 仅在后台使用 QImageReader，支持时缩放解码，自动处理图片方向。最终卡片物理尺寸不超过 256×192；缓存最多 64 张，原始卡片像素约 12 MiB 上限，不包括 Qt 图标/视图开销。
- 文件大于 64 MiB 或源图大于 4000 万像素不生成缩略图。损坏、不支持的图片保留普通文件图标，失败结果也缓存，避免反复尝试。
- 切换目录会清空缓存与排队请求、丢弃旧结果；关闭公共选择器销毁接收者及缓存，后台完成不访问已销毁窗口。应用退出使用既有 BackgroundTask 注册机制排空任务。静止时没有轮询。
- 透明图片缩略图使用白色衬底；原文件不被写入或转换。详情视图仍可通过文件选择器原按钮切换。
