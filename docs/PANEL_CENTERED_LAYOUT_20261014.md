# 任务栏居中设置（2026-10-14）

入口：任务栏空白处右键 → 外观与特效 → 液态外观设置。

## 行为

- “任务栏居中”控制整个任务栏，取消后铺满所在屏幕边缘。
- 居中长度可设为屏幕边长的 30–95%；水平任务栏调整宽度，垂直任务栏调整高度。100% 使用取消居中的全长模式，避免两个设置表达相同状态。
- 已有原生配置直接读取，打开设置不改动布局。再次开启居中会恢复上次选择的长度。
- 原生任务栏保留容纳图标的最小长度，因此实际长度可能比选择值更大。
- 滑块拖动期间只显示数值，松手后调整一次；键盘操作即时调整。没有新增常驻计时器、鼠标轮询或窗口位置修正循环。

## 接入方式

通过运行时查询 OEM `UKUIPanel` 的 Qt 方法 `setAlignment(UKUIPanel::Alignment,bool)` 和 `setLength(int,bool,bool)`，沿用原生几何、屏幕预留区域和配置保存处理，不使用私有字段偏移，也不自行调用窗口移动。

从当前面板对象名 `UKUIPanel <名称>` 对应的 `~/.config/ukui/panel.conf` 分组读取布局，原生接口保存最终布局；`~/.config/ukui/liquid-panel.ini` 的 `layout/<名称>/centeredLength` 只记录偏好的居中长度。没有兼容方法或无法确定面板名称时禁用控件并显示原因，避免误写其他面板配置。

## 验证

构建：`cmake --build apps/ukui-panel-liquid/build -j3`。

回归：在 `apps/ukui-panel-liquid/build` 运行：

```sh
ctest --output-on-failure -j2 -R '^(panel-theme|panel-corners-|panel-behavior-)'
```

9 项全部通过。覆盖实际设置入口、读取已有配置、原生接口调用、居中与全长切换、滑块松手一次更新、键盘修改、重新打开后的配置读取及保留固定应用记录。同时覆盖 1、1.25、1.5、2 倍缩放下已有菜单定位、任务视图和托盘弹层行为。

另以独立 Xvfb、D-Bus、配置目录运行本机真正的 `/usr/bin/ukui-panel`，通过鼠标和键盘操作设置页，在 1920×1080 屏幕取得：

| 状态 | X | 宽度 | Y / 高度 |
| --- | ---: | ---: | --- |
| 原有 68% 居中 | 307 | 1304 | 1030 / 50 |
| 关闭居中 | 0 | 1920 | 1030 / 50 |
| 重新开启 | 307 | 1304 | 1030 / 50 |
| 调至 95% | 48 | 1823 | 1030 / 50 |
| 重启原生任务栏 | 48 | 1823 | 1030 / 50 |

原生测试的日志、界面截图和几何结果保存在忽略目录 `apps/ukui-panel-liquid/build/artifacts/centered-layout/`。验证的是本机麒麟 V10 OEM 接口；其他 OEM 版本及多显示器、垂直方向仍需对应实机验收，不能由这次单屏水平验证推断全部通过。
