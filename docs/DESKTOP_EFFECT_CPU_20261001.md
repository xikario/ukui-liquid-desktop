# 桌面特效 CPU 优化（2026-10-01）

本轮优化系统监视、智能空间、Fences 分区、音乐小组件和原生任务栏插件。开始菜单的先前优化见 [独立记录](LAUNCHER_POINTER_REPAINT_20261001.md)。

## 行为与外观

- 保留玻璃材质、模糊/折射参数、渐变颜色、亮度、光照半径及悬停效果，不改变组件位置或资源采样间隔。
- 系统监视把同一 16 ms 内的鼠标移动合并，只更新旧/新高光经过的圆角边缘；修正组件自身缩放时鼠标坐标重复除以缩放值的问题。
- 智能空间保留 33 ms 光效响应与原有 52 px 激活距离、54 px 边缘渐变、148 px 弯曲光线。中间没有边缘光效的位置不触发材质重绘。
- 分区保留 33 ms、每帧 0.25 的原渐变与 0.015 收敛阈值。静止且达到目标亮度后停表，移动再启动；曲线覆盖使用 winding fill，避免磁吸轮廓的交叠区域遗漏。
- 音乐保留五枚矢量音符、33 ms 帧率、原速度、摆动、旋转、大小及透明度。每帧更新前后音符位置的并集；触及半透明按钮时完整刷新按钮轮廓，避免非整数 DPI 的 AA 边缘叠色。暂停、离线、隐藏时继续停表。
- 任务栏保留原 32 ms 合帧节奏和 95 px 反光半径。旧位置不再随每个鼠标事件立即重画，而与新位置一起合帧；离开、隐藏、控件销毁都清理待刷区域。

共享 `PointerEffect` 只观察原生鼠标和生命周期事件，不消费点击、拖动或菜单事件。忽略的鼠标移动继续传到父画布时，仍保留子组件的在场状态，避免把事件传播误判为离开并熄灭高光。跟踪包含子控件及后续创建的控件；非液态皮肤不调度无用的光效帧。离开窗口后结束渐变，不在静止、隐藏状态轮询鼠标。

## 验证

Fences 的 16 项回归全部通过：三组缩放下的实际 X11 backing-store 局部/完整重画对照、音乐播放与控制、智能空间交互、诊断/定位，以及分区功能和选择拖动。画面对照保留 2/255 的 Qt 抗锯齿通道容差；覆盖鼠标突然移动、圆角、磁吸轮廓、组件自身 0.8/1/1.2 缩放、音符越过封面/按钮和生命周期回绕。测试还验证合帧次数、有限受损区域、静止/隐藏停表及材质缓存复用。

```sh
# 在对应 build 目录执行；全部 UI 测试使用隔离显示与会话。
ctest --output-on-failure -j2 -R 'desktop_pointer_effect|desktop_music_|desktop_smart-interaction_|desktop_monitor_diagnosis|desktop_monitor_placement|fence_features|desktop_selection_drag'
```

任务栏的 5 项回归全部通过：实际原生窗口的局部/完整画面对照、子控件移动合帧、静止/离开不再绘制，以及既有圆角和设置检查。最终共 21 项，验证于 2026-10-02 完成。

本表使用单核 100% 的口径，固定在隔离 Xvfb、临时 HOME/XDG 与独立 D-Bus 中测试，缩放 150%、CPU 缓存材质、120 Hz 脚本鼠标路径，移动阶段采样 5 秒。任务栏为使用真实样式插件的控件夹具，不能等同于 OEM 任务/托盘插件的总开销。数值用于前后比较，不是日常桌面、GPU 或不同硬件的性能保证。表中为修正父画布事件传播后、确认高光在场的最终复测数据；舍弃了高光被误判离开的初步测量。

分区/智能空间静止、隐藏，音乐暂停/隐藏，以及任务栏静止/离开后的阶段均采样到 0%（不意味着永远无 CPU 工作）；系统监视保留采样任务，静止阶段约 0.6–0.83%。本轮没有降低数据采样或索引任务频率。
