# 智能空间文件夹导航与类型弹层 · 2026-10-03

本轮处理用户指出的左栏下半部空白、类型弹层没有液态材质及上下白线。保持上一轮的界面融合和边缘反光优化。

## 文件夹导航

左栏原有结构是根文件夹列表，选中后在其下追加匹配的下级目录；没有选中文件夹或没有匹配的子目录时，不会凭空显示一个下级区域。本轮美化没有删去此项功能。

发现根列表框体和末尾空白都设置了 stretch=1，导致只有根列表时可用高度被平分，较多文件夹被压在较矮的内部滚动区。末尾占位改为不争取额外空间，根列表使用剩余高度；多层导航仍按实际内容占用空间，需要时滚动。点击导航空白仍返回全部目录。

回归使用九个真实临时目录组、120 个虚拟文件，其中首组包含两个下级目录。核验根列表占满可用区域，实际点击后两个子目录出现，再点击空白返回九组，不依赖真实用户文件或索引。

## 类型弹层

主界面的 QComboBox 原先只禁用了弹层阴影，仍使用 UKUI 的菜单式下拉容器。它没有经过共享液态控件初始化；私有的上下滚动控件会显示不匹配的白色条带。

改为复用 `SettingsComboPopup::install` 和共享 `LiquidPopup::installComboPopups`：沿用普通列表、原生模型/选择/键盘行为，以桌面壁纸缓存提供液态材质，替换菜单式滚动控件，箭头使用统一矢量层。材质每次打开构建，关闭即释放，不添加持续光效或轮询计时器。

回归从实际类型控件打开弹层，检查液态材质、七项完整布局、无不透明白色滚动条带、键盘选择 PDF 后的可见无匹配结果，以及 Escape 不改变选择或隐藏智能空间。检查材质关闭后已释放。图片断言允许玻璃自身的细轮廓高光，不将它误判为系统的厚白条。
