# v0.7.0 · 液态材质、视频壁纸与办公桌面升级

日期：2026-10-08。汇总 v0.6.0 之后的三个应用及公共模块改动。本次为源码版本，Fences 核心和关于页为 0.7.0；开始菜单保留独立组件版本 0.2.0，任务栏保留现有插件身份。

## 液态外观与智能空间

- 玻璃缓存加入局部明暗遮罩、超椭圆内侧高光与静态颗粒，结合壁纸取色改善文字可读性。颗粒在材质重建时烘焙，复用全进程纹理。
- 悬停使用指数平滑；减少动态效果即时停止音乐装饰音符和图标点击动画，桌面刷新保留短暂静态闪亮反馈。
- 智能空间的搜索、工具栏、文件夹与结果列表融合为整体液态表面，保留选择和键盘焦点反馈。修复文件夹下半区域留空、类型下拉白条及末行裁切。
- 图标选择提供浅色背景以辨认透明图标；图片选择支持缩略图，统一按钮圆角与边缘绘制。

## 视频壁纸

视频壁纸保留实验性标识，使用硬件播放；液态玻璃复用首帧缓存，不逐帧重建。补齐循环转场、启动过渡层释放、持久预览缓存、小组件轮廓避让及任务栏壁纸同步。预览不再显示帧编号和采样时间说明。

视频按可见面积、隐藏、锁屏和电池状态暂停。主动隐藏后恢复从首帧播放，普通窗口遮挡恢复继续原位置；失败回到静态图片。支持不超过 60 秒、已知帧率不超过 120 fps 的本地短 H.264 MP4。透明窗口遮挡判断和 OEM 登录时序仍存在平台限制，详见 [启动与遮挡核验](../VIDEO_REVIEW_STARTUP_FIXES_20261006.md) 及 [小组件背景修复](../WIDGET_VIDEO_BACKGROUND_FIXES_20261006.md)。

## 音乐与任务栏

- 已启用的 MPRIS 客户端按正在播放、暂停、其余状态选择，同状态优先最后启动的；播放状态变化时实时切换，退出后回退。
- 元数据去重，封面与歌词合并到 120 ms 后处理；同一首歌信息更新不重置进度。歌词支持一行多个时间戳和全局 offset。
- 任务视图遵循隐藏设置；隐藏托盘图标向上展开，修复应用退出后的左右抖动、图标消失、布局缩减时悬空及提示残影。
- 动态三级菜单随尺寸更新显示区域，右键菜单依据按钮定位；修复托盘排序持久化。真实 Clash 三级菜单及退出抖动由用户确认解决，隔离测试覆盖动态菜单和事件触发。

## 验证与资源口径

功能收尾后完成三个应用构建和完整回归：Fences 110 项中 108 项通过、2 项 GPU 用例跳过；任务栏/公共模块 49 项中 48 项通过、1 项 GPU 用例跳过；开始菜单/公共模块 42 项中 41 项通过、1 项 GPU 用例跳过。公共用例在不同应用构建中有重复，不代表 201 个独立功能。

本次版本号提升后另行重建 Fences，设置中心在 1、1.5、2 倍缩放下的三项回归全部通过，71 个本地文档链接核验通过。本机备份后安装并正常重启 Fences，运行文件与构建文件哈希一致；小组件位置、系统监视和智能空间可见状态、视频选择及配置核验一致。关于页从应用版本读取 0.7.0；此次未重启整机。版本发布验证日志保存在本地 `apps/ukui-fences/build/artifacts/release-v070-20261008/`，不纳入 Git。

本机静态壁纸桌面连续 25 秒只读采样，按单核计算，Fences 平均 CPU 0.68%，任务栏 0.20%，开始菜单 0.00%。这是短时观察，不是整机压测或受控前后对比；视频助手当时未运行，不能推断视频总开销。视频性能必须包含助手、Xorg、KWin 和解码器，不能只看 Fences 主进程。测量条件、回归日志及六项修复见 [完整收尾记录](../REFINEMENT_CLOSEOUT_20261008.md)。

## 升级与边界

检出 `v0.7.0`，按 [构建说明](../BUILD.md) 构建三个应用，再按 [安装与恢复](../INSTALL_AND_RESTORE.md) 更新用户安装。公共模块为静态链接，依赖它的应用需要重建。更新前备份程序、配置和布局；本版本没有新的布局格式迁移。GitHub 提供源码 ZIP / tar.gz，不提供通用预编译安装包。

主要验证环境为银河麒麟 V10 / ARM64 / Qt 5.12 / UKUI X11。隔离显示服务器无法替代所有 OEM 合成器与真实开机时序，Wayland 不是完整支持目标。系统监视诊断仍只提供建议、复制及导出，不执行返回命令；智能空间保留本地检索。项目没有天气组件，本轮未实现天气缓存。保留上游署名与许可。
