# v0.5.0 · 桌面稳定性与文件操作升级

这是 UKUI Liquid Desktop 的首个带标签的源码版本，汇总公共液态模块、开始菜单、Fences 与小组件、任务栏插件，并收录最近一轮审查整改和稳定性修复。主要增量相对于此前远端主分支 `5633e7e`。

## 用户可见变化

- **文件夹拖放可撤回**：把文件或文件夹拖进另一个目录图标后，按 Ctrl+Z 或使用右键撤回，恢复原路径和分区/散落位置。目标图标重建不会丢失记录；部分失败可重试；不会覆盖原位置新出现的同名文件。
- **智能空间开合**：修复布局准备阶段窗口或星标短暂露出；缓存局部背景，减少动画过程中的重绘，快速反向切换延续进度。
- **登录与位置恢复**：四个小组件在读取智能空间大索引之前恢复；桌面首帧等待配置壁纸；系统监视保持保存的贴边位置。
- **响应性与材质**：文件操作、目录详情、壁纸解码、监视采样和开始菜单元数据等改为后台任务；公共模糊算法复用；修复气泡反向动画、混合屏幕坐标及最近文件解析。

## 升级

在仓库中检出 `v0.5.0`，按 [构建说明](../BUILD.md) 重新构建三个应用，再按 [安装与恢复](../INSTALL_AND_RESTORE.md) 更新用户安装。公共模块为静态链接，更新它们后需要重建并重启依赖应用。安装前备份现有程序和配置；本次没有布局格式迁移。

Fences 核心及关于页为 0.5.0；开始菜单等其他子项目保留自身版本号。GitHub 自动提供该标签的源码 ZIP / tar.gz；本次不发布通用预编译安装包。
