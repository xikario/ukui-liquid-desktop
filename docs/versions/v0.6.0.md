# v0.6.0 · 公共液态弹窗与桌面资源优化

日期：2026-10-03。本次为源码版本，包含三个应用及公共模块在 v0.5.1 之后的改动。Fences 核心和关于页为 0.6.0；开始菜单组件为 0.2.0，任务栏保留现有插件身份。

## 外观与资源

Fences、开始菜单和任务栏共用液态对话框、内部标题栏、按钮与下拉列表。设置、确认、输入和文件选择窗口按同一套生命周期准备背景、缓存材质，并在隐藏或关闭后停止动画工作。标题栏保留最小化和关闭，不提供最大化；普通任务窗口可以从任务栏恢复。

鼠标高光按输入事件合并更新，并限制重绘区域；静止或隐藏后停止光效计时。时钟镜片、菜单背景和控件材质继续使用缓存。音乐音符与倒计时等有实际状态变化的动画保留。没有降低折射、色散、高光参数，也没有通过关闭视觉效果实现优化。历史隔离性能对照见 [桌面光效优化](../DESKTOP_EFFECT_CPU_20261001.md) 和 [开始菜单重绘](../LAUNCHER_POINTER_REPAINT_20261001.md)。

## 窗口与交互

- Fences 分区右键设置合并至统一设置中心；清除分区图标需确认；支持当前系统主题图标及内置默认图标。
- 分区图标选择器与诊断详情使用对应的任务栏图标和身份。诊断导出窗口归属于诊断详情，沿用相同图标。
- 设置和诊断详情采用普通任务窗口，避免永久盖住其他应用；子对话框保留归属与模态关系。最小化、显示桌面和恢复路径纳入回归。
- 开始菜单首次显示等待正确背景准备，卸载确认前隐藏菜单，确认期间不会被 Win 键或再次打开请求盖住。正常应用不再提供删除快捷方式；只有启动失败并确认目标失效后，才建议清理用户快捷方式。
- 智能空间首次收起前完成按钮布局并校正当前边界，首次小图标位置与展开再收起一致。保留原有贴边算法和开合动画。
- 桌面空白处右键增加“打开终端”，使用桌面目录作为工作目录。
- 已有桌面项目拖到小组件附近时保持原目录，只调整图标位置；Ctrl 拖动复制仍创建副本。关闭淡出期间最小化或恢复，也会准确交付一次确认结果，避免后台模态等待。

## 发布前核验

本轮按应用拆分核验特效计时、材质缓存、窗口图标、父子归属、模态提示、焦点和最小化恢复，并扩展对应回归。三个应用完成构建；按修复后的最新结果汇总，108 项 CTest 通过、2 项隔离 GPU 用例跳过，另在真实显示器核验三个渲染器的 OpenGL 路径。本机安装后核对配置、布局、运行文件及任务窗口恢复，未进行整机重启。失败定位、复跑和具体边界见 [整体审查记录](../PROJECT_AUDIT_V060_20261003.md)。

## 升级与边界

检出 `v0.6.0`，按 [构建说明](../BUILD.md) 构建，再按 [安装与恢复](../INSTALL_AND_RESTORE.md) 更新用户安装。公共模块为静态链接，必须重建依赖它的三个应用。安装前备份已有程序、配置和布局；本版本没有新的布局格式迁移。GitHub 提供源码 ZIP / tar.gz，不提供通用预编译安装包。

主要验证环境为麒麟 V10 / ARM64 / Qt 5.12 / UKUI X11。隔离显示服务器可以验证控件与事件生命周期，但不能替代所有 OEM 合成器、系统弹窗和真实登录时序。系统网络、音量及部分 QML 弹窗属于独立宿主，不由本项目统一换肤；Wayland 不是完整支持目标。本轮不会把应用重启验证写成整机重启验证。

API 诊断保持建议、复制与导出能力，不执行返回命令；智能空间保持本地检索，索引和 Provider 按用户选择运行。用户布局、配置及第三方许可保持。
