# 智能空间复用分区玻璃（2026-10-15）

前三轮独立材质的深色暗槽和阅读保护仍被用户看成“大黑框”。本轮移除 `SmartSpaceOptics` 的双 SDF、厚暗槽和附加黑色遮罩，改为复用实际分区渲染链。

## 实现

- 智能空间在 DesktopCanvas 中直接调用既有 `renderLiquidGlass()`，复用同一个 `FenceGlassRenderer`、GL 后端和整幅壁纸预处理结果；不再保存独立背景裁片、清晰源或光学表。
- 使用与普通分区一致的 radius=10、scrim → grain → squircle edge 顺序及参数。没有叠加智能空间专用的 7:1 黑色遮罩；可读性沿用全局分区饰面预设。
- 窗口内侧保留 2 逻辑像素透明保护边，使抗锯齿边缘不落在 QWidget 的外边界上，修复 X11 局部重绘的细线残影；它不绘制黑边或阴影。同条件对照使用这个保护边内的实际取样位置和材质尺寸。
- 分区渲染器直接使用已有 GLSL/Snell 适配代码；本轮没有修改其着色器，也不把不同大小、位置、内容的两个窗口宣称为无条件“100% 像素相同”。同一背景取样、尺寸、DPR 和配置下，对照整个渲染链检查输出。
- 无 DesktopCanvas 的独立宿主才使用局部 FenceGlassRenderer 作为后备。生产中的置顶窗口仍保留画布父对象，并将全局位置转换为画布坐标，继续共享渲染。
- 增加 `liquidGlassReady` 通知：异步壁纸准备好后使智能空间缓存失效并重绘；快速换壁纸时丢弃过期准备结果，继续准备最新壁纸，不永久缓存暗色替代面板。
- 移动/缩放刷新采用 80 ms 尾部防抖。过程中拉伸旧缓存，停稳后生成新底图；平时的局部重绘、输入、滚动、指针反光继续复用材质。视频 coverage 使用最终实际像素，保留透明圆角。
- 原预览设置键 `smartSpace/glassOptics` 沿用，入口更名“分区同款玻璃（预览）”。关闭后精确恢复原柔光样式。

缓存命中意味着不重复执行着色器，不代表整个进程、文本排版、滚动、合成或视频播放的 CPU 开销为零。冷启动 GL 初始化和材质重建仍有成本；无 GL 时使用分区同一 CPU 回退，其外观不等于完整 GPU 折射。

## 验证与部署

四档缩放（1、1.25、1.5、2）的共享材质测试通过：受控取样下与分区渲染和收尾输出逐像素一致；输入、实际滚动与局部刷新复用底图；连续移动/缩放只在停稳后重建一次，壁纸扩散准备次数不增加；置顶转换仍使用画布坐标；换壁纸后收到准备完成通知并更新；原样式能精确恢复，视频覆盖区域来自最终材质。

三档指针回归检查局部与完整重绘一致，修复了初版贴边绘制在外侧一行/列产生的残影。另有壁纸同步、三档启动/隐藏定位、三档交互，以及分区 CPU 材质和启动壁纸回归通过。共 16 项 CTest 通过，1 项隔离 Xvfb GPU 测试因无可用 GL 上下文跳过。

真实桌面显示环境另行运行同一套材质测试，使用 `WA_DontShowOnScreen`，不映射测试窗口、不移动真实鼠标，并使用独立会话总线、配置、HOME 与合成文档。DPR 1.5 的实际 OpenGL 路径已通过全部断言；此结果与 Xvfb 的跳过分开记录。截图来自此 GPU 测试，不是 CPU 回退或图片后处理。

真实 GPU 测试中，单独宿主首次创建 GL 后端的冷构建观测约 715–981 ms；共享画布后移动/缩放的观测为数十至约百毫秒，不能外推成稳定帧率或“零开销”。本机部署日志确认首个分区 GL 初始化约 502 ms，之后智能空间实际尺寸 763×429 的共享 GPU 材质重建为 64 ms。普通交互不重复运行着色器，由缓存计数回归确认；没有作新的长期 CPU 或 GPU 占用测量。
