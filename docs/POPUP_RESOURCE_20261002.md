# 公共弹窗优化与本机验证（2026-10-02）

本次在 `shared/liquid-popup` 统一对话框、普通下拉列表、消息、输入与选择器，并优化菜单材质和高频悬停。保留折射、磨砂、高光、圆角、键盘操作及有限动画；三个宿主继续独立运行，不新增驻留服务。

## 实现范围

- 53 个静态消息入口和 3 个异步消息入口改用 `LiquidDialog`；智能空间 11 个包装入口和草稿确认复用公共表面，保留原有按钮及默认取消。
- 2 个名称输入、11 个文件/目录便利调用、1 个诊断导出选择器、5 个颜色选择入口接入公共表面。文件/颜色控件继续由 Qt 处理，文件选择明确使用进程内控件；覆盖确认走公共消息，选择器本身不写文件。
- 文件进度保留 Qt 进度控件、300 ms 显示延迟及“取消后续项目”语义。业务任务、光标和忙碌进度反馈仍正常运行。
- 开始菜单设置、面板设置、Provider JSON 编辑和独立智能空间设置复用对话框。Fences 主设置及诊断详情只加入有限开启动画，保留其已有材质准备与缓存，避免生成第二份底板。
- `SettingsComboPopup` 成为公共普通下拉实现的薄包装，保留壁纸来源。字体选择器保留字体预览 delegate，特殊 API 模型菜单保留业务控制。
- 仅显式接入产品自主窗口；外部 Peony 属性、系统控制中心、认证、通知和 OEM 自主窗口没有全局换肤。Qt 选择器内部校验继续由 Qt 处理。

## 节省重复工作

材质使用轴向几何数组及圆角采样缓存，缓存成本预算 2 MiB。每行顶部辉光只计算一次；使用连续像素写入。缓存键包含尺寸、DPR、圆角、折射参数及内容边界，背景本身每次打开重新取得。没有复用旧屏幕截图，也没有降低物理分辨率或改成较弱的光学效果。

菜单仅合并没有按键按下的高频鼠标移动，间隔由屏幕刷新率决定。点击、释放、键盘和离开菜单前提交待处理位置，仍使用 Qt 原生选中、子菜单、快捷键和动作触发。文字、字体、图标、可见布局未变化时跳过重复宽度测量，保留异步文字宽度预留。

面板参数立即更新，连续预览按 16 ms 合并，配置写入在停顿 180 ms、松手或关闭时完成。主题启停仍立即恢复/应用原生面板。透视程度、动画选项等不影响光学材质的变化只重绘，不重新准备壁纸。开始菜单设置初始化阻断透明度信号，一次保存四个字段，相同参数跳过应用。

对话框本次打开生成一次表面；焦点、输入、进度、移动和缩放复用冻结表面，隐藏时释放位图。动画均有限时长，静止没有额外循环。关闭期间禁用重复交互，快速重新打开取消待关闭状态；父对象销毁会清理动画和回调。

新增回归覆盖：当前背景更新与缓存上限、确认默认取消/Yes/Esc、输入确认与取消、文件和颜色选择、保存覆盖确认、进度取消、关闭释放、有限动画、重复关闭、快速重开、父对象销毁、下拉键盘选择、字体 delegate、高频悬停最终行与帧间点击。截图确认文字对比度；文件表头不继承列表内边距，避免文字裁切。

相关 CTest：Fences/公共模块 31 项、面板 6 项、开始菜单 6 项全部通过。另重跑 7 项布局/设置/启动检查（其中 6 项与前述重复），全部通过。合计 **44 个不同测试入口通过**。测试在 offscreen/Xvfb、独立 DBus 和临时配置中运行，不连接用户 API 或执行真实桌面文件操作。

## 同一隔离环境复测

Qt Fusion、150% UI、独立 Xvfb/DBus、合成背景；CPU 单核满载为 100%。材质测量每个尺寸/缩放预热一次，记录 8 次的中位数。优化前归档库和优化后库在本轮依次执行相同探针。以下只表示重复生成材质的暖缓存耗时，不包含真实抓屏、窗口映射、合成器和首个几何缓存构建。

| 逻辑尺寸 | DPR | 优化前 | 优化后 | 耗时下降 |
| --- | --- | ---: | ---: | ---: |
| 260 × 180 | 100% | 4.24 ms | 2.55 ms | 39.7% |
| 260 × 180 | 150% | 9.79 ms | 4.97 ms | 49.2% |
| 260 × 180 | 200% | 17.28 ms | 8.90 ms | 48.5% |
| 320 × 360 | 100% | 10.27 ms | 5.24 ms | 49.0% |
| 320 × 360 | 150% | 24.18 ms | 12.16 ms | 49.7% |
| 320 × 360 | 200% | 42.80 ms | 22.39 ms | 47.7% |

约 2 秒、8 ms 一次的跨行合成悬停：优化前发送 257 次事件，目标菜单 Paint 257 次、CPU 5.09%；优化后发送 249 次事件，Paint 113 次、CPU 3.35%（下降约 34.2%）。计时器调度使实际事件数略有差异，结果不是实际桌面的长期平均负载。

新公共确认框静止 CPU 约 0.0031%，目标 Paint 为 0。公共输入框光标保持闪烁，约 0.105%；活动进度约 1.34%。这些 2 秒短样本不能精确比较极低空闲 CPU，也不能将光标、进度动画归为浪费。目标 Paint 仅统计该窗口，不代表全部子控件和合成器工作。

连续开关 200 次确认框，200 次隐藏后表面字节数为 0。进程 RSS 在第 50 次后为 49.71 MiB，第 200 次后为 49.30 MiB；几何缓存计费约 543.8 KiB。仅支持本探针内未观察到持续增长，不能排除所有长期泄漏。

原生确认框原本已没有持续重绘。增加玻璃会引入一次打开计算和可见期间的位图内存；因此不能把统一换肤本身表述为整个桌面的 CPU/RSS 降低。节省来自共享计算、合帧、精准失效和及时释放。原高频桌面测试的 Fences 平均 11.39% 不能由本微基准重新归因。
