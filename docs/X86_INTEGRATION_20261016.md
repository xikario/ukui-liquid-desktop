## 任务栏居中的边界

正式“液态外观设置”仍优先且仅调用宿主的 `setAlignment(UKUIPanel::Alignment,bool)` 和 `setLength(int,bool,bool)`，缺少接口时禁用控件并提示原因。

X86 包保存的 `experiments/panel-centered-preview/` 是固定 68% 的独立兼容原型，不参与默认构建/安装，尚未接入正式设置和持久化。不能把原型实测成功理解为当前正式设置已支持缺少接口的 OEM 面板。多屏、自动隐藏、图标溢出和屏幕预留等正式化要求见[兼容调研](PANEL_CENTERED_COMPAT_RESEARCH_20261015.md)。

后续 X86 验收应记录控件是否启用、宿主版本、应用长度前后的实际几何及重启后是否保持；不要只核对配置值。

## 已知限制

- 原生菜单通知没有手势 ID，80 ms 延迟和松键后 250 ms 去重属于跨连接时间窗口策略，不宣称协议级精确关联。
- 菜单路由安装器处理可捕获失败的逆序回滚；跨目录发布不具备断电或 SIGKILL 下的整体原子性。
- 系统监控最多显示 32 个核心条；实际整机核心数仍按采样读取。
- 本轮仅合入代码，没有新增正式版本标签或 Release。
