# 系统监视与智能诊断

系统监视是 Fences 内的小组件，本地显示 CPU、内存、Swap、主目录所在磁盘、负载与高占用进程。可选智能诊断通过用户配置的 API 分析固定采样，不执行返回的建议。

[返回 Fences](../README.md) · [设置与显示](DESKTOP_MENU.md) · [v0.5.1 诊断面板实现记录](../../../docs/SYSTEM_MONITOR_DIAGNOSIS_PANEL_20261001.md)

## 打开与查看

桌面空白处右键 → **桌面小组件 → 显示系统监视**，或安装后运行 `~/.local/bin/ukui-fences-launcher --system-monitor`。自启动在 **Fences 设置 → 桌面小组件** 单独设置。

展开状态可查看资源图表、趋势和进程列表；标题栏双击或右键切换紧凑模式。移动、缩放需先开启桌面布局编辑。组件右键 **小组件设置**进入统一设置中心，皮肤与字体等设置在那里保存。

数值是采样时刻或采样区间的统计；磁盘图针对主目录所在文件系统，不代表所有硬盘。进程列表也不是完整进程管理器。

## 配置诊断 API

在 **Fences 设置 → 系统监视** 中填写 API 地址、密钥与模型，再点击 **应用**。组件隐藏时需明确启用，浏览设置不会自动开始诊断。

- 默认使用 DeepSeek Chat Completions 地址；其他兼容服务需自行确认支持相同请求格式。
- API 地址必须是有效 HTTPS URL，不能内嵌用户名或密码。
- **获取模型**查询该 Endpoint 的模型列表。自动获取项只允许选择，选 **自定义…** 后才显示手写模型 ID 的输入框；查询失败保留原选择。
- 设置提供 [DeepSeek 官方中文文档](https://api-docs.deepseek.com/zh-cn/) 链接。服务可用性、模型权限和额度取决于用户账户。

密钥优先保存在系统 Secret Service 密钥环，需要 `libsecret-1.so.0` 和可用、已解锁的密钥环。旧 INI 密钥只在迁移成功后移除；失败会提示，新输入仅本次运行有效。环境变量 `DEEPSEEK_API_KEY` / `DEEPSEEK_API_URL` 可用于当前进程配置，不会因为保存布局而把环境变量密钥写入 INI。历史配置备份仍需用户单独管理。

## 发起诊断

1. **整机趋势**：展开组件，右键 **DeepSeek 趋势诊断**。
2. **指定进程**：在高占用进程行右键，选择 **执行深度诊断 · 名称（PID）**。
3. 等待收集 **15 个有效样本**，界面显示采样对象和阶段进度；完成后固定采样、模型和请求配置，提交一次请求。
4. 双击诊断正文打开详情窗口；退出布局编辑后才能使用该双击入口。

目标进程使用 PID 和启动身份区分；进程退出时会保留退出信息，不把复用 PID 的新进程混进原诊断。实际时长受有效采样与 API 响应影响，不能把“15 个样本”理解为固定 15 秒后必有结果。

空正文、截断或无效结构结果最多补取一次，仍失败则展示原因；API 错误、拒绝及不支持的工具调用不会被当作成功结果。组件不会无限重试。

## 阅读、复制和导出

详情窗口包含 **诊断概览 / 详细分析 / 采样数据**：

- 概览显示状态、对象、模型、时间、采样进度和结论。
- 详细分析展示瓶颈、依据、短期/长期建议和命令卡片；非结构化回答保留全文。
- 采样数据区分本地预览与已经固定的请求快照，可复制 JSON。
- 支持复制摘要、全文、命令、采样 JSON，以及 TXT / JSON 文件导出。TXT 保留建议和风险，JSON 导出采样快照。

重复双击复用详情窗口，状态变化时更新；阅读中不会靠轮询反复重建正文。命令卡片是**只读文本**，没有执行、杀进程或自动修改系统的按钮。

## 数据与故障排查

主动发起 API 诊断会发送系统资源趋势、进程名称/PID及所选进程的资源、线程、状态、文件描述符和 I/O 等可读取信息；不上传完整命令行参数、文件正文、截图或密钥到采样 JSON。导出的数据仍含本机资源和进程信息，分享前应查看内容。

| 现象 | 检查方向 |
| --- | --- |
| 没有 API 结果 | 地址、密钥、模型权限、网络、额度与 curl 是否可用；本地监视仍可独立使用 |
| 进程明细缺失 | 进程可能已退出，或当前用户没有读取其 `/proc` 信息的权限 |
| 模型列表获取失败 | 确认服务提供模型列表接口；可使用自定义 ID，并保留当前选项 |
| 密钥无法持久保存 | 检查系统密钥环是否可用、解锁；界面会显示迁移/保存结果 |
| 无法移动或双击详情 | 移动需开启布局编辑；双击正文打开详情需退出布局编辑，并展开组件 |
