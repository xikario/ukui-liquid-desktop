# 音乐小组件与多客户端接入

音乐小组件通过会话 MPRIS 接口读取并控制播放器，不内置曲库、不负责音频输出。默认保留 Strawberry 配置，其他客户端需用户启用后才自动接入。

[返回 Fences](../README.md) · [显示与布局](DESKTOP_WIDGETS.md#入口与布局) · [多客户端实现与验证](../../../docs/MUSIC_MPRIS_CLIENTS_20261001.md)

## 推荐配置方式：先打开播放器

1. 手动启动希望接入的播放器；它必须提供 MPRIS 服务。
2. 进入桌面右键 **Fences 设置 → 音乐播放器**。
3. 从检测列表选择它，点击 **添加已运行的客户端**。系统尝试识别服务所属进程、程序、工作目录、AppImage 或原 `.desktop` 启动入口。
4. 检查识别结果，勾选客户端允许自动接入，点击 **应用**保存。
5. 桌面右键 → **桌面小组件 → 显示音乐播放器**。自启动另在 **桌面小组件**设置。

已有客户端可选中后点击 **从运行进程识别** 更新启动信息。此处不再弹出程序文件选择器；识别不完整时按下面的方式手工填写。添加、移除或编辑属于草稿，点击应用才影响当前音乐组件。

## 手动配置

点击 **手动添加**，填写：

| 字段 | 内容 |
| --- | --- |
| 显示名称 | 便于识别的名字，例如 YesPlayMusic |
| MPRIS 名称 | 例如 `org.mpris.MediaPlayer2.yesplaymusic`；匹配该服务及点号分隔的附加实例 |
| 启动程序 | 可执行文件的完整路径或程序名；可留空，运行中的客户端仍能接入 |
| 启动参数 | **每行一个参数**，不是整行 shell 命令；路径含空格也无需再加引号 |

自动识别到桌面入口时使用 gtk-launch，需安装 `libgtk-3-bin` 或发行版对应工具。启动程序和参数分开保存、直接执行，不解释 shell 管道、重定向或变量表达式。便携应用路径移动后需重新识别或更新。

未运行时，启动按钮优先使用上次接入且仍已启用、可启动的客户端；不可用时选择首个已启用且配置了程序的客户端。没有可用启动信息时，请先手动启动播放器再识别。

## 自动选择规则

只考虑用户配置中**已启用且正在运行**的客户端，同时连接一个控制对象。多个客户端同时运行时，优先选择正在播放的，其次暂停的，再其次停止或未知状态；同状态以服务所属进程的启动时间选择最后启动的。音乐卡片较晚打开也适用。播放状态变化后立即重新比较，不需要重启播放器。当前客户端退出后，回到仍在运行的候选；全部退出后清空歌名与封面。

不能读取进程启动时间时，按本次观察到的服务注册顺序回退；冷启动的同序候选按服务名稳定区分，无法还原未知的历史启动顺序。“最后启动”并不等于“最后播放”或“最后点击”。

切换控制对象不会暂停、退出其他播放器。Fences 自启动或显示卡片不会自动启动播放器或自动播放；隐藏卡片不停止音乐。新发现的客户端也不会未经配置自行启用。

## 卡片操作

显示客户端、封面、歌曲名、歌手、进度和音量。支持上一首、播放/暂停、下一首、拖动定位和音量调整；客户端不支持的能力会禁用。

点击封面或 **打开播放器**尝试前置当前窗口：使用 MPRIS Raise，X11 下也可按服务进程身份寻找并恢复最小化窗口。客户端无可用接口或可识别窗口时需从任务栏打开，不能保证所有播放器都能前置。

可见且播放时刷新进度和飘动音符；暂停、隐藏、被最大化窗口遮挡、退出或开启“减少动态效果”时停止音符动画。减弱动效不会停止音乐或必要的进度更新。当前实现为五个矢量音符，区域随卡片尺寸变化，复用底板缓存；动效不分析音频节拍。网络封面限大小、限时下载，失败显示默认图案。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 播放器不在检测列表 | 确认已运行并启用 MPRIS；无 MPRIS 的客户端仅填程序路径也无法播放控制 |
| 显示的是另一个客户端 | 查看启用列表、播放状态及进程启动顺序；不希望自动接入的客户端取消勾选并应用 |
| 点击启动无效 | 先手动打开，重新识别；检查便携路径、参数和 gtk-launch 是否可用 |
| 打开按钮不可用 / 不前置 | 确认客户端能力与窗口；可从任务栏打开，部分客户端的 Raise 实现无效 |
| 进度或音量不能拖动 | 客户端没有提供对应能力，或当前正在切换对象；不要依赖不支持的 MPRIS 控制 |

音乐配置保存在 Fences 用户配置的 `desklets/music/clients` 中。外观、移动、缩放与自启动沿用其他桌面小组件的规则，见 [小组件指南](DESKTOP_WIDGETS.md)。
