# 智能空间：本地索引、检索与预览

智能空间通过本地文件索引检索名称、路径和可提取正文，支持文件夹浏览及按需预览。当前界面不提供远程模型重排、联网问答、追问或多空间保存；顶部范围固定为 **全部文件**。

[返回 Fences](../README.md) · [知识库与 CLI](SMART_SPACE_KNOWLEDGE.md) · [设置入口](DESKTOP_MENU.md)

## 第一次建立索引

1. 桌面空白处右键 → **桌面小组件 → 显示智能空间**，或安装后运行 `~/.local/bin/ukui-fences-launcher --smart-space`。
2. 进入组件 **设置** 或 **Fences 设置 → 智能空间**，在 **索引范围**选择要扫描的目录及排除目录，在 **文件格式**选择索引格式。
3. 点击侧栏 **快全量**建立不含新 OCR 的文件快照。打开组件本身不会自动扫描。
4. 有扫描文档或图片时，在设置中启用 OCR，完成快全量后按需执行 **待检测**补充 OCR。
5. 以后用 **增量**更新变化文件；耗时任务可用 **暂停**停止并保留可恢复的检查点。

现有快照在后台读取、解压和解析，加载时界面保持可操作；这与重新扫描文件是两件不同的事。组件默认贴边隐藏，在 **更新策略**关闭“启动或启用组件后默认贴边隐藏”可改变该行为。显示、自启动在 Fences 设置中分别管理。

## 搜索与浏览

输入条件后按 Enter 或点击搜索。普通搜索把空格分隔的词作为多个条件；`re:` 前缀启用不区分大小写的 Unicode 正则表达式。

左栏沿文件夹层级向下浏览，右栏显示匹配文件。文件卡片可打开、预览及使用右键操作；窄窗口会收起文件夹栏。密度和排序可按界面控件调整，搜索条件仅保留在当前会话，不保存成独立空间。

**索引格式**决定扫描哪些文件；**结果显示格式**只控制已索引结果的显示，二者不是同一个开关。左栏隐藏文件夹也不等于排除扫描；要停止索引整个子树，使用排除范围并更新快照。

## 更新方式与资源边界

| 操作 | 用途 |
| --- | --- |
| 快全量 | 重新建立完整文件快照，不做新的 OCR，适合首次建库或目录范围大幅变化 |
| 增量 | 复用未变化文件的提取结果，更新变化内容；不会主动做新的 OCR |
| 待检测 | 对快全量中需要 OCR 的候选补充识别，需启用 OCR 及安装依赖 |
| 暂停 | 停止当前任务，保留已有结果与可用续扫状态 |
| 知识库建库 | 从文件快照提取正文片段到 SQLite，供本地正文排序检索使用 |

默认更新策略为手动；可选择文件变化或定时增量。当前 UI 发起的索引不按旧版 25,000 项截断，但正文长度、总预算、监视范围和提取依赖仍会影响结果完整性。快全量、增量和 OCR 补充的预算不同，“全部文件”不表示所有文档正文都已无损全文收录。

可处理 PDF、Office/ODF、部分 WPS 格式、文本与图片；实际提取取决于文件内部格式和依赖。PDF 文本/页面需要 Poppler，OCR 需要 Tesseract 及相应语言包。旧二进制 Office/WPS、加密或损坏文档可能失败或只能取得部分内容，文件名出现不等于全文提取成功。

任务在后台进程低优先级运行，更新成功才发布新快照，原文件只读。全量扫描和 OCR 仍会消耗磁盘、CPU 和时间；状态栏可查看进度及失败信息。

## 配置页面与数据

设置页包含 **索引范围、文件格式、更新策略、外观、知识库、Skill、数据源**。修改表单后点击应用/保存；未应用草稿不会成为正式配置。

| 数据 | 默认位置 |
| --- | --- |
| 组件配置 | Fences INI 的 `smartSpace` 分组 |
| 文件快照 | Qt 用户缓存目录下 `smart-space/index.json`，配套 `.ui.bin.gz` 用于流式读取 |
| 本地知识库 | `~/.local/share/ukui-fences/knowledge/smart-space-knowledge.sqlite`，可自定义目录 |
| Provider 配置 | `~/.config/kyfences/smart-space-providers.json` |

快全量与 OCR 使用独立续扫文件；不要仅删除数据库主文件而忽略正在运行的任务或 SQLite WAL。无需索引的个人目录可从范围中排除。

## 可选 Provider 与外部 Agent

默认文件提取、本地建库和检索不联网。**显式配置的 Provider 是例外**：索引器支持 Command、HTTP 和 D-Bus 数据源；Command 会运行本机程序，HTTP 可连接外部服务。带 Authorization、Cookie、X-API-Key 或 tokenEnv 的 HTTP 配置必须使用 HTTPS，不自动跟随重定向；无凭据的本地 HTTP 可用。只加载自己维护或审阅过的配置及其继承文件。

界面的 **Skill**页可查找、复制路径或导出已有 `ukui-fences-index-query` Skill。该 Skill **没有打包在仓库中**，需要事先安装到受支持目录；按钮存在不代表本机已经有 Skill。外部 Agent 可据本地检索结果继续研究，但其模型请求与数据处理由外部环境决定。

不使用 Agent 也能使用仓库自带的索引和知识库脚本；入口与完整命令见 [知识库指南](SMART_SPACE_KNOWLEDGE.md)。

## 故障排查与测试

没有结果时先确认已建立快照、目录在范围内、未被排除及显示格式未过滤，再检查提取状态。文件有变化但结果仍旧时执行增量；OCR 未完成时不要把“无关键词”当作原文没有该内容。知识库是派生数据，文件索引更新后还需更新知识库。

构建与测试命令从仓库根执行，见 [构建说明](../../../docs/BUILD.md)。索引/知识库单元测试为 `smart_space_indexer` 和 `smart_space_knowledge`；部分历史 UI 脚本仍包含已移除功能的断言，历史报告不代表当前全部测试通过。
