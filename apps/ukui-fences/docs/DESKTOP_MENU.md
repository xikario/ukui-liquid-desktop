# 桌面右键菜单与设置

适用于 v0.6.0。先显示 Fences 桌面，再在空白处右键。图标、分区和小组件的右键菜单各自提供对应操作。

[返回 Fences](../README.md) · [小组件指南](DESKTOP_WIDGETS.md)

## 桌面主菜单

| 入口 | 功能 |
| --- | --- |
| 新建 | 分区、从壁纸取色创建分区、文件夹及文档 |
| 粘贴 | 粘贴剪贴板中的文件；耗时文件操作在后台进行 |
| 撤销上一步 | 撤回本次运行中的可撤回操作；快捷键 Ctrl+Z |
| 刷新桌面 | 与 F5 相同，同步文件和元信息、恢复目录监听，并让图标短闪一次 |
| 打开终端 | 优先启动系统默认终端，工作目录为桌面；桌面目录不可用时进入用户主目录 |
| 打开文件管理器 | 进入文件管理器 |
| 编辑分区布局 / 退出布局编辑 | 控制分区及小组件移动、缩放；入口随当前状态切换 |
| 排列与布局 | 手动/名称/类型/修改时间排序；网格及布局备份在设置中心 |
| 桌面小组件 | 六类组件的显示开关，勾选反映当前状态 |
| Fences 设置… | 统一设置、帮助、关于及维护入口 |

旧版的“外观与特效”“设置与帮助”已合并进 **Fences 设置…**，不再是桌面主菜单入口。

刷新保留现有图标控件、选择及有效手动位置；已删除的文件会移除，新文件会添加。约 180 ms 的短闪用于确认操作发生，不通过隐藏整个桌面或重建所有图标实现。它不会自动重建智能空间知识库，索引更新需在智能空间内操作。

## 小组件显示与自启动

**桌面小组件**依次列出智能空间、系统监视、时钟与倒计时、活动统计、音乐播放器、日历与系统待办。

当前勾选只控制显示。要随 Fences 启动，进入 **Fences 设置 → 桌面小组件** 修改对应的“随 Fences 启动”选项。隐藏组件和取消自启动是两个不同操作。

开启布局编辑后可拖动分区及小组件，完成后退出编辑。小组件按钮在布局锁定时仍可使用；音乐等卡片可用自己的右键菜单隐藏。

## 设置中心

左侧分类包括液态外观、壁纸与配色、图标与文字、分区与布局、桌面小组件及专项配置、文件同步、帮助与维护。

外观开关即时生效；带应用按钮的表单需点击 **应用** 后保存，切换页保留草稿，关闭时提示未应用修改。隐藏的智能空间/系统监视需明确启用后配置，浏览设置页不会自动发起扫描或采样。

**帮助与维护**提供使用说明、关于、切换系统桌面与退出。分区右键的 **分区设置…** 会直接打开该分区的完整配置页。液态图标底座在 **图标与文字**，布局备份在 **分区与布局**。

## 分区右键设置与标题图标

分区标题栏、分区内容空白处都提供单一 **分区设置…** 入口。旧的颜色、透明度、图标、标题字体、内部图标字体入口统一收进设置中心的对应分区页；重命名、折叠、锁定、排序和文件操作保留为快捷操作。也可以从 **Fences 设置 → 分区与布局 → 分区名称 · 分区设置** 进入。

标题图标可选：

- **系统与默认图标… → 系统图标库**：搜索当前系统主题、继承主题及兜底图标。保存图标名称，跟随系统图标主题变化；主题暂时没有该图标时显示内置兜底图标。
- **内置默认图标**：提供轨道、任务、行业资料、项目与服务、演示素材、临时停泊、收件箱、归档、灵感和收藏十个图标，打包进程序。
- **从图片文件选择…**：保留 PNG、JPEG、SVG、ICO 等图片路径。

**清除分区图标…** 会弹出确认，默认选择取消；确认后恢复未设置图标的小框占位，不修改分区和文件。清除结果在重启后保留。

图标库只在打开系统图标页时于后台读取目录；同名图标的不同尺寸合并，列表按需显示，搜索短暂合并输入。关闭窗口取消未完成的读取。

## 公共气泡预览

`liquid-popup-preview` 是独立交互预览程序，示例复选项和子菜单不修改产品设置。当前主菜单与设置页没有独立的“液态气泡预览”按钮；安装时默认与 Fences 放在同一 bin 目录，可直接运行：

```sh
~/.local/bin/liquid-popup-preview
```

开发构建路径为 `apps/ukui-fences/build/liquid-popup/liquid-popup-preview`，是否构建由 `UKUI_FENCES_BUILD_POPUP_PREVIEW` 控制。路径请以实际构建目录为准；单独构建方式见 [公共菜单模块](../../../shared/liquid-popup/README.md)。
