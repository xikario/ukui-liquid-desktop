# 桌面右键菜单（2026-09-27）

桌面空白处右键，主菜单保留 9 个入口：新建、粘贴、撤销上一步、刷新桌面、编辑分区布局、排列与布局、桌面小组件、外观与特效、设置与帮助。

布局编辑入口随状态切换：平时显示“编辑分区布局”，开启后显示“退出布局编辑”。统一控制分区及六个桌面小组件的移动、缩放。

- 新建：普通分区、从壁纸取样创建分区、文件夹及各类文档。
- 排列与布局：手动/名称/类型/修改时间四种互斥排列方式，图标网格，布局导入、导出、重置。重置仍需确认。
- 桌面小组件：显示智能空间、显示系统监视、显示时钟与倒计时、显示活动统计、显示 Strawberry 音乐、显示日历与系统待办；复选标记反映当前组件状态。
- 外观与特效：分区液态玻璃、液态气泡预览、主题配色、桌面字体、系统壁纸、Fences 壁纸。
- 设置与帮助：桌面文件同步、启动设置、应用外部主题文件、文件管理器、使用说明、关于、切换系统桌面、退出。

启动设置单独控制智能空间、系统监视、时钟与倒计时、活动统计、Strawberry 音乐卡片、日历与系统待办的自动启动，与当前显示状态分开。每项同时显示勾选状态及“已开启自启动 / 未开启自启动”文字；点击后同步更新并保存，避免主题下原生勾选不明显。

## 公共液态气泡预览入口

桌面空白处右键 → 外观与特效 → 液态气泡预览…

预览窗口展示开始菜单、智能空间、ukui-fences、系统监视共用的气泡与菜单效果。窗口内的复选项和子菜单是交互示例，不修改应用设置。分区液态玻璃开关只控制分区材质，不控制公共气泡。

构建默认启用 `UKUI_FENCES_BUILD_POPUP_PREVIEW`，同时构建和安装 `liquid-popup-preview`。入口优先查找 Fences 可执行文件同目录，再查找 PATH，开发构建还支持构建产物路径。安装时应将两个程序放在同一 bin 目录。

分区标题栏和文件右键菜单维持原有行为。
