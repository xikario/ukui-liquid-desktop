# 时钟与倒计时、活动统计、Strawberry 音乐、日历（2026-09-28）

这是 NextKde DeskCenter 的 Qt5 / UKUI X11 适配，参考提交及许可见 vendor/nextkde-desklets。
不需要安装 Quickshell 或替换系统桌面。

## 入口与布局

桌面空白处右键 → 桌面小组件 → 显示时钟与倒计时 / 显示活动统计。
桌面右键 → 设置与帮助 → 启动设置，分别设置随 Fences 启动。
启动项保留对号和“已开启自启动 / 未开启自启动”文字。
默认时钟为 220×250 逻辑像素，活动统计为 360×220 逻辑像素；活动统计参考原版采用左右双栏。
时钟、活动统计、音乐和日历统一取消右上角 ×。组件右键 → 隐藏组件，或桌面右键 → 桌面小组件取消显示；不会关闭播放器或清空数据。
桌面右键 → 编辑分区布局，开启后拖动标题移动、拖动右下角调整大小；点击“退出布局编辑”后锁定位置和尺寸。倒计时和统计按钮在锁定时仍可操作。
桌面文件、文件夹图标会避开可见组件及其周围 8 像素间距；组件移动、缩放、显示或隐藏后重新检查图标布局。
旧版未调整的默认尺寸会自动迁移到紧凑尺寸，自定义尺寸保留。
首次放置避开现有分区及小组件；之后保留用户的位置，并在屏幕变化时约束到可见区域。
编辑时拖动标题，距屏幕边缘 32 逻辑像素内吸附，可贴齐顶部和四边；距相邻组件或分区 12 逻辑像素内贴靠、对齐。没有强制外边距，重新显示或重启保留已保存位置。

## 时钟与倒计时

指针钟、数字时间和日期；倒计时支持 5/15/25 分钟预设及 1–1440 分钟输入。
运行中可暂停、继续和取消。到点通过桌面通知和提示音提醒。
截止时间、暂停剩余时间和页面状态持久化。Fences 重启后恢复，到点仅通知一次。
关闭自动启动后，下一次登录不会启动该组件，因而也不会在组件未启动时发出倒计时通知。

## 活动统计

显示最近 60 天开机时长和今日应用前台停留时长排行；放大卡片可显示更多应用，最多 8 项。
开机时长来自 /proc/uptime，包含锁屏及休眠；首次启用能读取本次开机的真实时长。
应用时长从首次启用开始记录，不补造以前的应用历史。前台停留不等于有效工作时间。

仅保存 WM_CLASS 对应的应用名称和累计时长，不读窗口标题、文档名、键盘输入。
X11 前台切换事件触发结算，5 秒兜底采样，60 秒原子保存，退出时保存。
锁屏、暂停记录、桌面/任务栏、本程序窗口和异常长计时间隔不计入应用时长。
隐藏卡片继续统计；使用“暂停记录”明确停止应用记录。开机累计仍更新。
数据位置：~/.local/share/ukui-fences/widgets/activity.json。
同一 boot_id 仅增量记账，Fences 重启不会重复累计；跨午夜分日。

## 材质与资源

四个新组件共用 LiquidDesklet 底板、shared/liquid-glass 光学渲染器以及 shared/liquid-popup 菜单。
壁纸从 DesktopCanvas 最新缓存取样，壁纸变更、移动、缩放时刷新材质。
时钟每秒仅重画内容；活动数据刷新不重算光学纹理。隐藏时不绘制卡片。
不新增常驻独立进程、屏幕截图轮询或 60 FPS 动画。

## Strawberry 音乐

桌面右键 → 桌面小组件 → 显示 Strawberry 音乐；设置与帮助 → 启动设置可单独控制卡片自启动。
音乐卡片默认 360×180 逻辑像素，共用 LiquidDesklet 外观、壁纸更新、编辑开关、贴边/贴靠、位置保存和图标避让。

展示封面、歌曲名、歌手、进度和音量；支持上一首、播放/暂停、下一首、拖动进度、音量调整。点击封面或“打开播放器”唤起 Strawberry。
未运行时显示启动按钮，优先使用本机便携版 strawberry-1.2.26，随后尝试 PATH 中的 strawberry。
卡片随 Fences 自启动不会主动启动播放器或自动播放音乐；关闭卡片不会停止音乐。

只连接 org.mpris.MediaPlayer2.strawberry，通过异步 MPRIS D-Bus 收发，不接管播放列表和音频引擎。
播放器退出清空旧歌名/封面，重新启动自动连接。按播放器能力禁用不可用的控制项；换歌期间拖动的旧进度不会错误应用到新歌。
可见且播放时进度每秒本地推进，每 10 秒异步校准；暂停、停止或隐藏时停止进度定时器。进度更新不重建液态材质。
播放时封面周围有 6 个小音符上浮、轻摆、淡入淡出；暂停、停止、隐藏或播放器退出时清除音符并停止动画定时器。约 30 帧/秒，只刷新封面附近 104×120 逻辑像素，复用玻璃材质缓存，不遮挡歌名和控制按钮。
动效设计参考 [Groove Index 的 Floating Musical Notes](https://github.com/NainaKothari-14/groove-index/blob/main/README.md)（播放时音符上浮、旋转、淡出）；本项目使用原创 Qt QPainter 矢量绘制，未引入该项目代码、素材或网页运行时。动画随播放状态运行，不分析音频节拍。
封面支持本地文件和 HTTP(S)，同一 URL 复用当前缩略图，下载限 8 MiB、8 秒超时，缩略图上限 256×256；失败使用默认音乐图案。

CTest desktop_music_1 / desktop_music_1.5 / desktop_music_2 使用隔离总线和模拟 MPRIS 播放器，验证控件、拖动定位、音量、状态同步、封面缓存、退出重连、隐藏不停止播放、图标避让、编辑锁定、贴边和重启恢复。
编译增加 Qt5 Network 依赖；本机 SDK 的 libQt5Network.so.5.12.12 链接到系统相同版本运行库。

## 日历与系统待办

参考 NextKde 同一提交的 DeskCenter calendarContent 大日期/月历布局（来源与许可见 vendor/nextkde-desklets），Qt5 液态适配，默认 400×390。周一为每周首日，按月份实际周数排布，今日高亮、有事项日期加点。可翻月、回今天、选择日期筛选、点击“全部”查看读取范围内事项。

桌面右键 → 桌面小组件 → 显示日历与系统待办；启动设置有单独开关。沿用编辑锁定、吸附、文件图标避让、壁纸跟随。

系统数据源为 XDG_CONFIG_HOME/.kylin_calendar_Schedule2.db 中的 Schedule，使用 Python 标准库 SQLite 只读模式，由短时异步进程读取，超时中止。文件和 WAL 变化后合并刷新，不常驻轮询进程；可见时每分钟检查跨日。读失败保留最后一次内容并显示提示，不写数据库、不复制待办、不额外发送提醒。
如果外部待办同步程序已写入该系统日历，组件直接展示同一份数据。系统库没有完成字段，旧日期标注“已过日期”，不推断完成状态。
默认读取当前月以及今天前30天/后90天，远期翻月只读取目标月；“全部”指这段范围而非无限历史。普通、全天、跨天事项支持，常见公历重复按范围展开；未知或农历重复显示提醒，仍应由系统日历确认。
点击待办或“系统日历”通过 org.ukui.calendar.Notifications.OpenSchedule 打开对应日期，由系统程序新增、修改、删除。

新增 scripts/calendar_snapshot.py 随程序安装在 bin 目录，开发构建可从源码路径读取。
测试：calendar_snapshot 验证只读、缺失文件、跨天/重复；desktop_calendar_1/1.5/2 验证真实隔离 SQLite 读取、外部增删改和原子替换、日期筛选、无关闭按钮、图标避让、编辑锁定、贴边、启动恢复。

## 日历的显示与选择

右上角减号收起下方待办、加号恢复；保留用户设置的展开高度。年份和月份分别打开最多五行的滚轮选择器，支持滚轮/拖动、点击或 Enter 确认，Escape 取消。
农历通过系统 ICU 计算；法定放假/调休来自随源码提供的 2026 年 holiday-cn 数据，其他年份不推断官方调休安排。
